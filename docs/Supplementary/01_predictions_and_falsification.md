# Supplementary Material S11. Systemic Osteogenic Set-point (SOS) theory — predictions and falsifying tests

This supplementary file operationalises the theoretical framework referenced in the main manuscript §4 (Biological context and predictions). It lists the six predictions (P1–P6) generated by the Systemic Osteogenic Set-point (SOS) theory and the five falsifying tests (F1–F5), with the current paper's judgement on each. It is provided so that reviewers can verify the theory's claims against the reported evidence without relying on the main text alone.

## Core proposition

Common genetic variation sets a life-long, systemic bone-forming set-point, readable as areal BMD at any site. The set-point has **opposing-endpoint consequences**: at the whole-bone strength endpoint it is protective (against fracture); at the joint (osteochondral unit) endpoint it is pathogenic (raising OA risk through subchondral bone formation / osteophytes and TGF-β/WNT/BMP crosstalk).

## Predictions and current judgement

| # | Prediction | Evidence in this study | Judgement |
|---|---|---|---|
| **P1** Opposing endpoints | One BMD-raising profile protects against fracture yet raises OA risk | Positive control OR 1.40 (1.34–1.46) per SD lower BMD; BMD→knee-OA 5/5 positive (β +0.017 to +0.028) | Supported |
| **P2** Systemic, not local-mechanical | OA effect should not be largest at weight-bearing / joint-proximal sites; non-weight-bearing / axial sites should be ≥ femoral neck | Lumbar spine +0.028 (largest) > arms +0.022 > femoral neck +0.017 (smallest); lumbar least explained by height | Supported (discriminating; site differences within sampling error, not formally tested) |
| **P3** Diffuse polygenic | No single locus should show BMD–OA colocalisation | 0/31 loci PP.H4≥0.8; strongest locus would need ~5×10⁷ participants (~42× present) for genome-wide significance | Supported (null is the predicted outcome; not discriminating between diffuse mechanisms) |
| **P4** Size is a separable partial component | Conditioning on height attenuates the OA effect but not the fracture effect | OA attenuation 6–33% (vs Table 3); fracture positive control moved only −1.7% to −2.8% (mass-transparent) | Supported (residual mass-vs-size split not identified) |
| **P5** Asymmetry is constitutional | Reverse (OA→BMD / OA→fracture) should be null, because a late, local disease cannot shift a life-long systemic set-point, and OA's bone effect is local | Reverse null (power 0.14–0.26) | Direction consistent + underpowered (both stated; power limitation not substituted for theory) |
| **P6** Site pathway dominance | Effect direction varies with joint dominant pathway: knee (systemic/metabolic) positive; hip (morphological/mechanical) reversed or attenuated | This study: knee positive. Literature: Zhou et al. [5] femoral-neck protective (hip); Hartley et al. [22] hip OR 1.28, knee OR 1.40 (both positive); Funck-Brentano et al. [36] hip OR 1.23, knee OR 1.20 (both positive) | **Weakened to a magnitude claim.** Hip evidence is internally contradictory (protective [5] vs harmful [22],[36]). Under the conjunctive falsification rule F1, Hartley et al. establishes positivity at the hip but not equality with the knee (log-OR 0.247 vs 0.336, 27% lower; overlapping CIs). Prior on F1 shifted against P6; F1 decision rule pre-registered (see below). |

## Falsifying tests (prospective)

| # | Test | Design | Falsification condition |
|---|---|---|---|
| **F1** Site pathway dominance | Repeat the ten-site design with **hip OA** as outcome | If hip OA effect is positive **and at least as large as** the knee effect → P6 fails (set-point would be whole-joint systemic, not knee-pathway-dominant) |
| **F2** Mass/size decomposition | Conditional MR with vBMD / hip geometry / bone-area GWAS as a second exposure | If adding a true size phenotype attenuates the effect far beyond 33% → P4 residual is not "bone" |
| **F3** Mechanism localisation (bone vs cartilage side) | LDSC-SEG / MAGMA tissue enrichment of BMD instruments in osteoblast/bone vs chondrocyte/cartilage | If enrichment is in cartilage → mechanism direction overturned |
| **F4** Tissue-context colocalisation | eQTL colocalisation: bone-tissue eQTL↔OA vs cartilage eQTL↔OA (PP.H4 comparison) | If cartilage PP.H4 is systematically higher → "bone-driven" overturned |
| **F5** Phenotype stratification (cheapest, highest value) | Re-run MR stratifying OA outcome by osteophyte-predominant (hypertrophic) vs joint-space-narrowing-predominant | If the effect does not concentrate in the osteophyte-predominant subtype → K6 / bone-forming-programme hypothesis overturned |

**Honest boundaries (also in main-text Limitations):** SOS is inferred from the genetic architecture plus published biology, not directly measured; all BMD phenotypes are areal DXA and do not resolve subchondral micro-structure/turnover; P2 site differences are within sampling error and were not formally tested; Hartley et al. [22] reported bidirectional effects, in tension with this study's unidirectional conclusion (sources of difference not adjudicated here); F3/F4 skeletons exist (`code/40_tissue_enrichment.py`, `code/41_eqtl_coloc.py`) but were not executed (require LDSC-SEG weights and eQTLGen downloads). F5 is the highest-yield, lowest-cost test and is recommended as the immediate next step.
