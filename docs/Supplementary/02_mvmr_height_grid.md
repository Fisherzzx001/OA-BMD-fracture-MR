**Note on the attenuation columns (corrected 2026-10-16; β columns re-scaled 2026-10-20 with the G6 N·K(1−K) correction).** `Atten% vs Table 2` = 100×(β_uni(Table 2) − β_MVMR)/β_uni(Table 2); `Atten% vs BMD-subset` = 100×(β_uni(MVMR set) − β_MVMR)/β_uni(MVMR set). Both are ratios and therefore invariant to the N-scale correction; they agree with Table S9 for the primary EUR / n_h=100 configuration (19.1 / 14.6 / 27.6 / 13.5 / 33.2% vs Table 2 and 9.8 / 14.6 / 9.5 / 11.0 / 21.2% vs the MVMR-set baseline). **Negative values mean the MVMR estimate moved _away_ from the null relative to that baseline** (i.e. the effect strengthened under conditioning), which occurs in the degenerate n_h=0 rows where no height instrument is conditioned on but the restricted instrument subset changes the univariable reference; the primary n_h=100 rows are positive throughout for the OA-knee outcomes.

> **Note (2026-10-20 audit).** For the n_h=0 rows the MVMR model contains no height instruments (K = n_bmd), so no direct height effect θ_H or conditional F for height is estimable; those cells are shown as '—'. Values previously printed in these cells were rank-deficiency artefacts of the regression and are withdrawn. The n_h=0 rows are retained only as the BMD-only univariable baseline.
