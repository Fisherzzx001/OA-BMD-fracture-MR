## 二、P0 阻塞级问题

### P0-1【最严重】Table 3 的同一行里，不同列来自两个不同的仪器集

**事实：** 项目存在两套仪器集——
- **严格 clump**（primary，Table 3 的 n_snp 列）：K = 16/21/24/25/31/69
- **宽松 1-Mb clump**（`mr_results.csv` 的 n_snp）：n = 17/22/24/25/26/31/79

独立重算（`AUDIT_mr_recomputed.csv`，基于严格集逐 SNP 数据）与 Table 3 逐值比对：

| 对 | n_snp（严格） | Table 3 值 | 独立重算（严格集） | 差异 |
|---|---|---|---|---|
| **OA knee → BMD total** | 69 | Egger 截距 p = **0.039** | **0.376** | **显著性反转** |
| **OA knee → BMD femoral neck** | 69 | Egger 截距 p = **0.030** | **0.169** | **显著性反转** |
| BMD femoral neck → fracture | 25 | 0.010 | 0.018 | 不一致 |
| BMD femoral neck → OA knee | 25 | 0.907 | 0.875 | 不一致 |
| BMD lumbar → OA knee | 21 | 0.240 | 0.295 | 不一致 |
| BMD arms → OA knee | 16 | 0.973 | 0.982 | 不一致 |
| OA knee → fracture | 69 | 0.456 | 0.476 | 不一致 |

**10 对中有 7 对的 Egger 截距 p 来自宽松集；6 对的随机效应 p 来自宽松集（如 OA knee→BMD total p_re：Table 3 = 0.4994，严格集重算 = 0.4813）。**

**为什么严重：**
1. Table 3 中 0.039 与 0.030 会暗示「反向 MR 存在方向性多效性」，但严格集（稿件自己声明的 primary 仪器集）重算是 **0.376 / 0.169，完全不显著**。审稿人若自行重算，会发现稿件自相矛盾。
2. 与 §3.4「MR-Egger intercepts all p > 0.24」的叙述直接冲突——Table 3 里有两行是 0.039 和 0.030。
3. 表格中 n_snp 标 69，但旁边列的数字实际由 79 个 SNP 算出。

**修正方案：** 以严格集（K）为准，重算并统一 Table 3 的 Egger β／截距 p／I²／p_re／wmed。修正后反向 MR 的 Egger 截距全部不显著，**结论反而更干净**（反向 null 不再受多效性质疑）。

### P0-2【单位错误】OA_knee 的效应量被标为 log-OR，实际是标准化尺度

**独立判定方法：** 由 β = z/√(2pq·N_eff) 反解每个性状的 N_eff，与理论值对照。

| 性状 | 实测 N_eff（中位） | 若 log-OR：N·K(1−K) | 若标准化：N | 判定 |
|---|---|---|---|---|
| **fracture** | **31,103** | **32,459** | 264,973 | ✅ **log-OR**（吻合） |
| **OA_knee** | **1,152,869** | 127,607 | **1,208,397** | ✅ **标准化尺度**（吻合） |
| BMD_total | 31,871 | — | 31,873 | ✅ SD 单位 |

OA_knee 实测 N_eff ≈ 1.15M，若它是 log-OR 应 ≈ 128k——**相差 9 倍**，排除。

**后果：**
1. `build_figures_mr.py:132` 把 `OA_knee` 列入 `BINARY`，图轴标 **"log-OR per allele"** → Figure 6c、6d 与 S1a–f 的 OA_knee 轴 **标签错误**（应为 "SD per allele" 或 "standardised effect per allele"）。这个错误是 v6 修图时引入的，前两轮审计均未发现。
2. §3.4「at K=0.12, total-body BMD gives OR ≈ 1.02–1.05 per SD」——这是把标准化 β 直接 exp() 的结果（e^0.0231 = 1.023）。正确换算：β_logit = β_std / √[K(1−K)] = 0.0231 / 0.325 = 0.071 → **OR ≈ 1.07**。

**修正方案：** ① 图轴标签改为 "standardised effect (SD) per allele"；② §3.4 的 OR 换算改为正确口径，或（更稳妥）**直接删去 OR 换算，只报标准化 β**——因为该换算依赖 OA_knee 的标度假设，而这一假设本身需外部确认。
