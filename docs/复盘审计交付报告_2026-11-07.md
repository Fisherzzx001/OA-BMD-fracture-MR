### 2.2 发现的真实缺陷（已修复）
- **【D1·已修复】§57 效应尺度校正叙事过强**：原句"all inferential quantities (z, p, …) are unchanged; only absolute effect sizes move" 与文件矛盾。独立比对 `mr_results.csv`(原始) vs `mr_results_corrected.csv`(终版) 显示：total-body 与 leg 为纯缩放（z/p 不变），但 **femoral-neck(26→25 SNP)、lumbar(22→21)、arms(17→16) 三对在校正中各丢了 1 个 SNP，z/p 实际改变**（如 lumbar p 1.87e-8→7.70e-9）。稿件 Table 2 数值本身正确（= corrected 文件），但 §57 措辞不属实。已重写为："…unchanged where the harmonised SNP set is identical (total-body and leg BMD); for the femoral-neck, lumbar and arms pairs the reconstruction also changed the harmonised SNP count (26→25, 22→21, 17→16)…The Table 2 estimates are the final reconstructed values."
- **【D2·已修复】审计轨迹泄漏 + 打包缺陷**（见 §6）。

### 2.3 门禁评估（关键元发现）
`code/148`(OAC 格式) / `code/149b`(数值安全) / `code/182`(终检) 三道门禁**仅校验字符串与格式，不校验统计数学正确性**。因此"门禁全绿"不能证明数据正确——这正是本轮审计的价值所在：在门禁全绿下仍发现并修正了 D1 叙事缺陷。
