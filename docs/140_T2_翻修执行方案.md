## 2. 翻修后 T2 设计（3 层，成本递增）

### Tier-1 （F3, 成本最低, 立即可跑）— MAGMA 基因集：骨发育 vs 软骨发育
- **数据**：已缓存 GWAS munge 汇总统计（OA_knee / BMD_total / fracture，即 code/29 同批 `07_reference/ldsc/sumstats_*.sumstats.gz`）+ MAGMA 二进制(~10MB) + 1000G SNP→基因映射(.bim, ~100MB) + GO 基因集。
- **方法**：MAGMA `--bfile` 出基因级 p → competitive gene-set 检验，对比
  `bone development`(GO:0060348) vs `cartilage development`(GO:0051216)（含骨软骨形成、软骨内成骨等相关 GO 项作敏感性）。
- **回答 Reviewer 1**：OA/BMD/fracture 遗传性是否在"骨发育/成骨"通路富集高于"软骨发育"通路 —— 直接机制旁证，零外部 eQTL 依赖、完全可复现。
- **诚实边界**：通路级富集，非组织内 eQTL 中介直接证据（与 F4 互补，不冲突）。

### Tier-2 （F3, 中等成本）— MAGMA gene-property：GTEx v8 54 组织表达
- 下 GTEx v8 标准化表达矩阵（按组织，单组织 MB 级），`--gene-property` 看 OA/BMD/fracture 遗传性在哪些组织富集；重点看骨邻近/间充质组织（Muscle-Skeletal, Artery-Tibial）排序。
- **注**：GTEx 无软骨，故"骨 vs 软骨"组织对不全在 GTEx 内；Tier-1 的 GO 基因集补此缺口，二者并列。

### Tier-3 （F4-literal, 高成本, 用户原意）— 骨/软骨 eQTL coloc（复用 `code/41 eqtl`）
- **软骨侧**：Southam **FunGen cartilage eQTL**（low-grade + high-grade intact/damaged）
  `personal.broadinstitute.org/ryank/Southam_FunGen_eQTL_{LowGradeCartilage,HighGradeCartilge}.FastQTL_perm_nom_info.ForMSK-KP_16Jan2021.zip`
  → 真实软骨 eQTL（FastQTL nominal）；需转 `CHR/BP/SNP/A1/A2/MAF/N/Z`（Z=beta/se，N 取 FunGen 队列规模，MAF 取参考）。
- **骨侧（proxy）**：**skeletal muscle bulk eQTL meta**（GTEx+FUSION, Wilson 2025；Zenodo 16647432 / mohlke lab）
  `Muscle_eQTL_MetaAnalysis_fullMarginalSumStats_hg19.tar.gz`（~4GB，含 chr/pos/EA/NEA/EAF/Beta/SE/pval + SNP_N，列齐全）。
  → 间充质/骨邻近标准代理（肌与骨同属中胚层、共享调控程序），样本量大、格式干净。
- **执行**：新增 `code/167_eqtl_format_harmonize.py`（统一两源为 `code/41` 期望的 `CHR BP SNP A1 A2 MAF N Z`）→ `python code/41_eqtl_coloc.py eqtl <muscle> <cartilage> <muscle_N> <cartilage_N>` → PP4(muscle_eQTL,OA) vs PP4(cartilage_eQTL,OA)，闭合"骨驱动软骨"组织判别。
- **诚实边界（必须披露）**：
  - 骨侧为**肌肉 proxy**（非真骨）；软骨侧 FunGen 真软骨但 **N 较小** → **样本量不对称**（肌肉 meta 数千 vs 软骨数百），检验功效偏向骨侧；须报告双臂 N 并做功效敏感性（如按软骨 N 下采样肌肉做对称对照）。
  - FastQTL nominal 与肌肉 meta marginal 格式异构 → 需统一转换；MAF 取自参考（1000G/EA），与 eQTLGen AF 同源处理。

### 已完成
- **F3（骨 vs 软骨 组织富集，competitive gene-set）** — `code/171_f3_geneset.py`
  - 数据：UCSC hg19 refGene（基因坐标，7.7MB）+ OA_FLAGSHIP/07_reference/ldsc 全基因组 munge 汇总（`sumstats_oa_knee` / `sumstats_total` / `sumstats_fracture`）。
  - 方法：SNP→基因体 ±50kb 映射；基因级统计量 = 窗内最小 p；每个 GO 基因集 vs 背景做单侧 Mann–Whitney U（−log10p）。
  - GO 成员：QuickGO 抓取 9 个骨/软骨相关 GO term（`code/170_fetch_go.py` → `go_genesets.json`）。
  - 结果（落 S24）：**OA_knee 偏好软骨侧基因集**（cartilage_development Δ=+2.43 p=1.5e-8；chondrocyte_differentiation Δ=+2.33 p=1.6e-8）显著强于骨侧（bone_development Δ=+0.81 p=2.2e-4）；**BMD_total 偏好骨侧**（skeletal_system_development Δ=+1.73 p=1.3e-4）；fracture 侧软骨集略强。→ 组织特异性成立：OA 负荷于软骨基因、BMD 负荷于骨/骨骼系统基因。
- **F4-literal 软骨臂（FunGen 低级别 OA 软骨 eQTL）** — `code/172a_cartilage_eqtl_loci.py` + `code/172b_f4_literal_coloc.py`
  - 数据：FunGen cartilage eQTL zip（1.25GB，已解压 inner gz）→ 31 个 BMD_total 工具位点 ±500kb 窗内逐 SNP 最强软骨 eQTL（N≈200，Z=slope/se）。
  - coloc.abf（复用 code/29 引擎，先验同 S8）对 OA_knee / BMD_total / fracture。
  - 结果（落 S25）：三者在 31 个位点 **0/31 达 PP.H4≥0.8**（OA median 0.009；BMD median 0.061；fracture median 0.002）。→ BMD 工具位点不与软骨调控变异共享因果；与"形成侧（骨/软骨下）而非软骨基质"解读一致，并平行于既有 cross-trait 臂（同批仪器与骨折[骨]共定 9/31、与 OA[关节]0/31）。
