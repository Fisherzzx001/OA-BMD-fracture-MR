## 3. 深化理论贡献的补强空间（核心）

### 3.0 Reviewer 1（理论贡献质询师）的尖锐版

> "去掉这篇论文，领域会少什么？"——**真实答案存在**：①把临床"骨密度悖论"用遗传学重新框定为单一 set-point；②coloc 端点分裂（0/31 vs 9/31）证明 OA 链接**不走系统性 BMD→骨折通路**；③SOS 作为**可证伪**（F1–F10）假设。这三点足以撑起一篇 OAC original article。
> **但天花板清晰**：SOS 目前是"讲得通的故事 + 6/10 证伪通过"，机制层面（骨驱动软骨）只有文献底座（99b）与跨性状 coloc，**缺组织级遗传证据**。Reviewer 1 会问："bone drives cartilage 这个核心机制主张，你的数据在哪？"——当前答案是"在文献里，不在你的汇总统计里"。这是必须补的最后一环。

### 3.1 【Tier 1 · 最高 ROI · 现有数据零新样本】双轴潜结构 → SOS 从隐喻升级为数据衍生 construct

**背景**：SOS 当前是叙述性隐喻（"一个可被 areal BMD 读取的多基因骨形成 set-point"）。`docs/99b` 已把机制锚定到骨–软骨单元，但仍未把 SOS 本身变成**可量化的潜变量**。

**本轮回溯 rg 矩阵做的 PCA 探针（探索性，未入稿件）**：
```
输入：code/output/genetics/rg_matrix_13.csv（13×13，含符号）
方法：对相关矩阵做谱分解（numpy.linalg.eigh）

PC1 解释方差 = 66.7%    ← 单一主导轴
  载荷：BMD_total −0.326, BMD_trunk −0.330, BMD_spine −0.313,
        BMD_pelvis −0.316, BMD_lumbar −0.303, BMD_femur_total −0.302,
        BMD_arms −0.302, BMD_femur_neck −0.300, BMD_leg −0.298, BMD_rib −0.298
        （10 个 BMD 部位载荷均匀 ~−0.30，符号任意）
        fracture +0.184（与 BMD 反向）
        OA_knee −0.069, OA_selfrep −0.078（≈0，不在该轴上）
PC2 解释方差 = 14.1%
  载荷：OA_knee −0.686, OA_selfrep −0.679（主导）, fracture −0.246, BMD≈0
两轴合计 = 80.8%
```
**解读（关键、反直觉、更锐利）**：13 表型的遗传相关结构**不是单轴，而是双轴**——
- **PC1 = BMD↔骨折轴**（系统性骨强度轴）：BMD 部位高度一致地载荷，fracture 反向，OA 几乎不载荷。
- **PC2 = OA 轴**：OA 定义主导，fracture 弱反向，BMD 不载荷。

**这对理论的提升（三重）**：
1. **SOS 的"set-point"被数据坐实**：PC1 正是"骨形成 set-point"的潜变量化表达（高度一致、解释 2/3 方差）。
2. **解释了 BMD→OA 为何温和且端点特异**：OA 在 BMD↔骨折轴上≈0，BMD→OA 是**跨轴耦合**（cross-axis），天然小于同轴的 BMD→骨折效应（OR 1.06–1.10 vs 1.40）——与 coloc 0/31 互为正交证据。
3. **把 §4 L93 的"not via systemic pathway"从 coloc 功效依赖，升级为结构证据**：OA 轴与 BMD 轴正交，是独立的遗传架构事实。

**落地方式**：新增 §2 小节"Latent structure of the 13-phenotype r_g matrix"（EFA 亦可，PCA 足矣）+ 补充图 S22（双轴载荷双射图：PC1 vs PC2 散点，BMD 簇 / OA 簇 / fracture 分置）。成本：数小时（矩阵已在仓）。**须诚实标注局限**：OA 的 h² 低（0.035）→ 其 r_g SE 较大 → PC1 上 OA≈0 可能部分受估计噪声放大，需用更高 h² 的 OA 定义或更大样本复制（即与 F1 髋 OA 复制协同）。

> ⚠️ 注意：此发现**微调而非推翻** SOS 叙述——它把"单一 set-point 同时驱动两端"修正为"set-point 是 BMD↔骨折轴；OA 是与之正交/弱耦合的第二轴"，反而更精确、更经得起审稿人追问。

### 3.2 【Tier 1 · 高 ROI · 现有数据】闭合 OA→fracture 的 r_g↔MR 矛盾（MVMR）

**现状（§4 L97 与 Limitations）**：knee-OA × fracture r_g = +0.119（p=3.1×10⁻⁹，正相关）但 OA→fracture MR 为 null（β=+0.027, p=0.40）。稿件说"该调和**未经多变量 MR 检验**"。

**补强**：以 BMD 为协变量的 MVMR（OA→fracture | BMD）。预期：BMD 介导成分方向相反（高 BMD 升 OA 却护骨折），故条件 BMD 后 OA→fracture 的残差应更接近零或转负——直接闭合"相关≠因果"的公开缺口。成本：中（需 OA→fracture 的 BMD 条件 MVMR，工具已在仓）。价值：把一个 Limitations 条目变成一段正面论证。

### 3.3 【Tier 2 · 机制金标准】骨 vs 软骨 组织富集 + eQTL coloc（F3 / F4 字面臂）

**现状（§4 L95）**：F4 跨性状臂已执行（9/31 vs 0/31, p=0.0043）；eQTLGen **blood** 臂已执行（p=0.001156）但"blood 非骨非软骨，组织字面臂未执行"。F3（LDSC-SEG 骨 vs 软骨富集）前瞻。

**补强（99b §5 蓝图，脚手架已备 `code/40`,`164`,`41`）**：
- LDSC-SEG（`code/164_ldsc_seg_native.py`）对 BMD 汇总统计做骨/软骨细胞类型谱富集；
- 骨 eQTL（GTEx 成骨细胞/软骨下骨）vs 软骨 eQTL 对 31 位点的 coloc（F4 字面臂）。
**价值**：把"骨驱动软骨"从文献底座变成**本研究的遗传证据**——这是 Reviewer 1 那句"你的数据在哪"的终极回答。
**成本**：高（需下载 LDSC-SEG 53 组织权重 + GTEx/eQTLGen 骨/软骨 eQTL，数 GB；本机 `data/` 现仅有 height + eQTLGen blood）。**建议作为返修或第二稿的旗舰增项**，而非阻塞本轮投稿。

### 3.4 【Tier 3 · 转化】set-point PGS 外部验证

**补强**：用 31 个 BMD 工具（或 BMD PGS）在独立样本（UKB holdout / 外部队列）中同时预测骨折（保护）与 OA（风险升高），演示 set-point 的**临床可读性与外部效度**。
**价值**：把遗传学发现拉到转化层，顶刊青睐。
**成本**：中（需独立结局样本；UKB 自身即可做内部验证）。**注意**：属"验证"非"发现"，须在方法学上避免过拟合（需严格 held-out）。

### 3.5 【Tier 3 · 机制】中介 MR 提名具体通路

**补强**：若有下游中介 GWAS（软骨厚度、骨转换标志物 P1NP/硬化蛋白、软骨下 BMD），做两步 MR 中介，检验 BMD→OA 是否经特定中介。
**价值**：把 SOS 从"假设"推向"机制路径提名"。
**成本**：取决于中介 GWAS 可得性；高风险高回报。**F2（体积/尺寸分解）是更优先、更干净的机制检验**——建议先 F2 后中介。

### 3.6 【Tier 4 · 概念精修】DAG 化 + 性别/激素调制

- **DAG**：把 SOS 画成显式有向无环图（遗传 set-point → 系统性 BMD → 软骨下重塑 → 软骨；set-point → 骨折），F1–F10 映射到节点/边。提升顶刊理论清晰度（OAC 临床受众尤需）。
- **性别/激素调制**：F8 已证两性均 +；可进一步问 set-point 是否受雌激素调制（绝经后骨丢失），加 menopause 分层或性激素 GWAS 条件——新颖性中，成本中。
