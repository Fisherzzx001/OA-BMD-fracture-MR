> 关键约定（本轮独立实现并 debug 确认）：
> - **IVW**：weight = 1/se_ratio²，se_ratio = se_o/\|β_e\|；β = Σw·ratio / Σw
> - **随机效应（TwoSampleMR 约定）**：SE_RE = SE_fixed·√(Q/df)，β_RE = β_IVW
> - **MR-Egger**：项目采用 β_outcome ~ β_exposure，权重 1/se_outcome²（conv2）；截距=定向多效性，斜率=因果效应（已写调试脚本精确复现 BMD_total→fracture 截距 −0.00202, se 0.00344, p 0.558）
> - **加权中位数（Bowden 2016 non-extrapolated）**：中点累积权重 p_j=(cum_j−0.5·w_j)/tot ≥ 0.5
