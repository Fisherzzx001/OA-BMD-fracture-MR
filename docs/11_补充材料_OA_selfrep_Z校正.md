# 补充材料 S2：自我报告 OA（OA_selfrep）等位基因方向——基因组级独立验证
（投稿前整改三项必改之 ①；稿件 §2.4 / §2.6 / §5 第 8 项）

---

## 1. 背景

跨性状遗传相关与 MR 对**等位基因方向**极度敏感。同一 SNP 在不同 GWAS 中可能因
A1 选择、链（strand）或编码方向不同而出现符号差异。本分析使用 **chr:bp 键**
（绝不用 rs_id）做等位基因 harmonisation（见 `code/09_rg_matrix.py`）。

## 2. 历史：早期文件曾需全局翻转

一个**早期** OA_selfrep 文件（占位 N = 350,000）的 Z 与 A1 整体反号，曾用
`SIGN_FLIP = {"OA_selfrep": -1}` 校正。当时的诊断依据是两个无可争议的 OA 因果
哨兵（GDF5 rs224333、FTO rs9930333）在 OA_knee 与 OA_selfrep 中呈**相反** Z 符号，
外加外部文献锚点（Hackinger 2017；Zhou 2025）。该论证依赖"OA_knee × OA_selfrep
这对的不一致推导出翻转、又用它验证"——本质上是**循环论证**，是全文最脆弱的单点。

## 3. 2026-09-26 重新 munge 改变了文件状态

OA_selfrep 汇总统计于 2026-09-26 重新生成：样本量更正为真实的 **462,933**
（IEU OpenGWAS `ukb-b-14486`，38,472 cases / 424,461 controls），且等位基因方向
变为与独立生成的膝 OA GWAS **一致**。**当前 live 管线已将 `SIGN_FLIP` 置空**
（`code/09_rg_matrix.py`），不再施加任何全局翻转。

因此，旧的"两个哨兵相反"诊断描述的是**重新 munge 之前的旧文件版本**，对当前
文件已不适用——这正是为什么必须用独立、基因组级的方法重新验证，而不是沿用
那两个哨兵。

## 4. 基因组级独立验证（本整改核心）

**参照对象**：OA_knee（GO Consortium 2025, *Nature*，稿件 Ref 1）——一个**独立
生成**的膝 OA GWAS，其方向即"已发表的 OA 风险方向"，不依赖本分析内部的任何
OA_selfrep 推导。

**方法**（`code/42_selfrep_validation.py`）：在 OA_knee 全部 **1,980 个基因组
显著位点**（|Z| > 5.45，P < 5×10⁻⁸）上，比较 OA_selfrep 的 Z 符号与 OA_knee 的
一致性（原始 vs 翻转后），并按染色体分解。

**结果**：

- **原始（未翻转）一致性 = 94.4%**（1,870 / 1,980）；
- 翻转后一致性仅 5.6%——说明若对当前文件**再施加一次翻转反而会破坏**方向一致性；
- 逐染色体原始一致性 84.9–100%（chr18 仅 9 个 SNP，66.7%，属小样本异常）。

**哨兵复核（当前文件）**：GDF5 knee Z = −13.675 / self Z = −4.244（**同号**）；
FTO knee Z = +12.905 / self Z = +2.201（**同号**）。二者在旧 doc 11 中记录的
"相反"来自 pre-remunge 文件，现已过时——当前文件在两个经典 OA 位点上已与
OA_knee 同向。

**结论**：当前 OA_selfrep 文件在基因组尺度上与独立 OA_knee GWAS **高度一致**，
**无需全局翻转**。验证首次脱离两个哨兵的循环论证，建立在 1,980 个独立 OA_knee
基因组显著位点的全基因组证据之上。

## 5. 与遗传相关的一致性

`rg(OA_knee, OA_selfrep) = +0.838`（SE 0.018，P ≈ 0），与"同一疾病两种定义应
强正相关"的生物学预期一致。该值在全局 690,150 SNP 共同集上经
`code/45_regen_selfrep_row.py` 重算确认（当前 concordant 文件、不施加翻转），
与重新 munge 前（discordant 文件 + 翻转）得到的结果在三位小数内一致——说明
无论经"旧文件+翻转"还是"当前文件+无翻转"两条路径，生物学真值（强正相关）均被
保留，但**当前路径不再依赖任何方向假设**，更为稳健。

## 6. 对结论的影响

Z 方向只影响**符号**，不影响 LDSC 的 r_g 幅度，也不影响 MR 的**方向/显著性**
（r_g 与 N、M 无关，已实证 N 变动 6.7× 时 r_g 三位小数不变）。本整改仅改写
rg 矩阵中 OA_selfrep 一行的生成方式（去掉冗余翻转），OA_selfrep 不是任何 MR
暴露（见 §2.6），故不影响 §3 的 MR 方向、显著性或效应量，也不削弱任何主要结论。
