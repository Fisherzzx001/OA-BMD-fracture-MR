# 【Reviewer 1】理论贡献质询师

SOS（系统性成骨设定点）理论把一个悖论转成了一个可向外延展的预测体系 —— 这一步做对了，并且优于此前版本。但理论的**第六条预测现在被论文自己引用的文献推翻**。

### 漏洞 1（致命）：P6 已被 ref [22] 预先证伪，而论文把 ref [22] 放在两段之后

§4.3 P6 断言膝关节走"系统性骨形成"通路、髋关节走"形态/力学"通路，并在 F1 中明确预登记了失败条件：
> "(F1) Repeating the ten-site design with hip OA as the outcome: **if the effect there were positive and of the same magnitude as at the knee, P6 would fail.**"

而 §4.2 引 Hartley et al. [22] 报告：
> "a causal effect of higher BMD on **hip OA (OR 1.28, 95% CI 1.05–1.57)** and **knee OA (OR 1.40, 95% CI 1.20–1.63)**"

Hartley 的髋 OA 效应**既阳性、量级又与膝相当（1.28 vs 1.40），且 CI 排除 1**。按你自己预登记的判据，**P6 已经失败**。论文在两个段落之间完全没有处理这个冲突：一处用 Zhou [5] 的"股骨颈保护髋 OA"支撑"髋由形态力学主导"，另一处引用 Hartley 的"BMD 致髋 OA OR 1.28"，二者对髋 OA 的结论正相反，却从未被摆在一起 adjudicate。

这不是遗漏，是**选择性引用支撑预设立场** —— 而这恰恰是理论工作最致命的一种失败。

### 漏洞 2：理论的核心构念与其操作化测量互不兼容

SOS 把"设定点"定义为终身系统性骨形成倾向，操作化为 "readable as areal BMD at any site"。但论文自己（§4.2、§3.10）用了大量篇幅论证 **areal BMD = BMC/面积，混合了骨量与尺寸，且本设计无法拆分**。

于是：你的理论变量用了一个你自己论证为"不可识别的复合变量"来测量。若未能拆分 mass/size，"set-point" 就不是一个被识别的构念，而是一个占位符。这在学理上等于：**理论宣称解释了什么，取决于一个本文承认测不准的量**。

### 漏洞 3：理论的真假依赖 GDF5/coloc null 的"预测"叙事，但那是弱预测

P3 把 "0/31 locus colocalises" 说成"被预测的实现"。然而 §3.9 自己算了：期望 |z| 中位数 0.30 —— **任何**弥散多基因机制都会给出这个 null。论文实际也承认（§4.2 尾）"remaining equally compatible with any other diffuse mechanism and so not discriminating between them"。既然不具判别力，P3 就不能算作理论得到支持的证据，只能算"未被驳倒"。把它列入"supported"的六预测之一，是把**不可证伪项计入支持**，属于理论记账。

**深化方向：** 把 P6 改写为真二选一并把 Hartley 放进账内重算（例如"若髋 OA 在更高功效下复现阳性且与膝同量级，则部位通路优势假设失败，set-point 应理解为全关节系统性"）；把"set-point"操作化到可拆分的表型（vBMD/髋几何）或明确降格为"待测量aproxy"。

| Arms | +0.02218 | 16 | +0.02156 | 15 | +0.02036 | **−8.2%** |
| Legs | +0.01772 | 24 | +0.01502 | 21 | +0.01348 | **−23.9%** |

两个独立的硬问题：

**(a) 工具数不一致且未说明。** Table 3 用 31/25/21/16/24 个严格 clump 工具；MVMR 管线用 27/23/19/15/21 个 —— 每个位点少 1–4 个。§2.10 却写"BMD instruments were the strict-clumped per-site SNP sets of §2.6"，暗示未变。**减少几个工具就让股骨颈估计改变 26.8%**，这本身说明该估计对工具组成高度敏感，与论文反复强调的"方向一致、结论稳健"形成张力，必须显式报告为敏感性分析。

**(b) 衰减率的口径依赖未被披露。** `mvmr_height_grid.csv` 同时存在两套衰减：
- `atten_vs_full`（论文采用的）：9.5–21.2%
- `atten_vs_bmdsubset`（论文从未提及）：total 6.2% / **femoral neck 32.7%** / lumbar 17.4% / arms 5.8% / leg 12.2%

**换一个同样合理的基线定义，股骨颈的"尺寸归因比例"就从 14.6% 变成 32.7%** —— 而 §3.10 撑起的"≈79–90% 独立于身高–size 通路"、§4.2 的"骨量份额为 UPPER BOUND"、乃至新理论的 **P4**，全部建在这一个未报告的选择之上。审稿人一旦发现，整条 size/mass 论证链的可信度会被重估。

**(c) `uni_beta` 随 n_h 漂移，定义不明。** BMD_total：`n_h` = 0/100/300/1000 时 uni_beta = 0.01996 / 0.02074 / 0.01850 / 0.02041。一个"单变量基线"随第二个暴露的工具数变化，说明它不是常规意义的单变量估计。**必须在 §2.10 给出其定义式**，否则 §3.10 的衰减率读者无法复现。

**整改要求（三选一，但必须做）：**
1. 说明 MVMR 与 Table 3 工具数差异的原因（哪些 SNP 被丢弃、为何）；

3. 统一管线，使 S9 的 Uni β == Table 3 的 IVW β。

### M2（P0）：S9 表注的衰减定义式**符号错误**

第 416 行写：`"Atten. %" is ... 100 × (β_MVMR − β_uni)/β_uni`
