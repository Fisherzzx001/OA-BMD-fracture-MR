## 2. R3 缺失对话三项（建议补，非致命）

### R3-1 机制桥接 [35–38] —— 成立，已补
- **核验**：成立。原文 L93 首句仅把骨软骨单元作背景罗列，未与自己的 MR 结果建立方向关系。
- **修正**：`OA is a disorder of the osteochondral unit [35–38] in which subchondral remodelling feeds cartilage degradation; the set-point we instrument acts upstream of it.`
- **理由**：把 `[35–38]` 的软骨下骨重塑→软骨降解链条与本稿 instrument 的系统性设定点连成上下游关系，且不额外声称本 MR 测到了该单元内的过程。

### R3-2 骨改良药流行病学 —— 成立，**但补出来的结论比 R3 预期的更锋利**
- **核验**：成立；但检索到的事实**与本稿结论存在真张力**，而不是简单佐证：双膦酸盐**升高** areal BMD，使用者膝置换风险却**更低**（RR 0.71, 0.66–0.77）。
- **源核实**：Cui B, Chen Y, Tian Y, Liu H, Huang Y, Yin G, Xie Q. *Adv Rheumatol* **2022;62:22**（PMID 35761320，doi:10.1186/s42358-022-00253-4）。PubMed 摘要与出版商 DOI 落地页逐值一致（队列 RR 0.71 [0.66–0.77]，I²=0，2 项队列；校正 aHR 0.76 [0.70–0.83]；40 项研究 / 6,041,254 人）。
- **修正**：增补一句并据此**收紧 SOS 构念**——若设定点泛指"密度"，会被该证据直接反驳；因此明示落在**形成侧而非再吸收侧/密度本身**。
- **诚实边界**：只用 RR，不宣称药物效应；原文自陈合格研究少、异质性高，这是稿件不把它当因果依据的原因。

### R3-3 反向因果文献 —— 成立，**且把本稿的 null 从"矛盾"翻转为"与流行病学一致"**
- **核验**：成立。原稿 L97 以只做 verbal reconciliation 处理 `r_g>0` 但 `MR null` 的反差。
- **源核实**：Hardcastle SA, Dieppe P, Gregson CL, Davey Smith G, Tobias JH. *BoneKEy Rep* **2015;4:624**（PMID 25628884，doi:10.1038/bonekey.2014.119）。关键：OA 者 BMD 更高，但骨折率**没有下降**（部分研究反而升高），而该关联在**校正跌倒后大幅衰减**。
- **意义**：这正是本稿 null MR 所预测的方向——骨密度通道不产生保护，观察到的关联来自跌倒而非骨。因此 null **不是与观测证据相冲突，而是与之收紧**。附加收益：这篇综述与 [39] 是同一课题组，且明文提出"识别主要由骨形成增加驱动的 OA 表型"，进一步说明 SOS 构念在文献中先存。
- **注意**：本文=A2 检索时曾先命中硬化蛋白/心血管 MR 文献，与 OA 风险无直接关系，已弃用，未引入。

## 6. 本轮自身缺陷与修复（照录，不掩饰）

2. **重编号脚本漏处理混合区间**：`code/188_renumber_refs.py` 的正则 `\[([0-9,\s]+)\]` 不匹配 `[29–30, 40]` 这种含 en-dash 的混合组，导致 Estrada 未随 40→42 迁移，出现 `[42] never cited` FAIL。已手工修 `[29–30, 40]` → `[29–30, 42]`。**保留在案：脚本未重构为通用形式，后续若再插入文献需重跑并复核混合组。**
3. **引用序非线性引发的重编号级联**：新增两条文献首次出现在讨论，早于原 [40–43]，违反 OAC "按首次出现编号"。处理：40/41 ← 新文献（Cui / Hardcastle 2015），原 40–43 顺延 42–45。
4. **门禁陈旧（用户事前点名的类型）再次出现一次**：`code/182` L199 把 TREASURE 锚定在写死的 `[42]`，重编号即误报。已改为**语义锚** `refnum("Sobue Y")`——这正是前两轮同类问题的第三例，说明"数字/原文快照做锚点"是该代码库的系统性风险面。
5. **回读发现指代歧义**：插入的 `that reconciliation` 紧贴 `genetic correlation is not causation`，最近先行词被后者偷走。已重排为紧贴其所修饰的和解陈述。
