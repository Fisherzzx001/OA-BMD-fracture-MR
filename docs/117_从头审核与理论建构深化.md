## 3. 补强空间：按杠杆排序

### Tier 1 — 高价值、低成本、当前即可做（不改已报统计量）
1. **为本研究单独 OSF 预注册**（L0 补强）：把设计 + P1–P6 标为 derived、F1–F5 标为 registered extensions；时间戳即优先权。成本=写作半天。
2. **F5 骨赘为主 vs JSN 为主分层 MR**（113/101 共识"最便宜最高价值"）：需带放射学亚型的 OA GWAS；以同一骨折阳性对照重跑，检验效应是否集中于增生型。这是**对 SOS"骨形成程序"最直接的可证伪检验**。
3. **性别分层 MR**（稿件 §4 Limitations 已自承"material limitation"）：BMD 与 OA 均性别二态，全部估计为 sex-averaged。UKB/IEU 均支持按性别拆分，可行性高，且能直接回答"成骨程序是否性别特异"——顶级期刊极看重。
4. **部位梯度正式检验**（P2 当前"差异在抽样误差内，未正式检验"）：对 5 个 BMD→knee-OA β 做 bootstrap 对比（lumbar vs FN 等），把"系统性 > 局部力学"从观察口述升级为带 p 的判别。
5. **祖先敏感性**（祖先错配主局限）：对 knee-OA 做 EUR-only 子集 MR 或留非欧子集，既缓解局限又是"成骨程序跨祖先复现"的理论检验。

### Tier 2 — 高价值、需下载/第二暴露（理论建构主载荷）
6. **F3/F4 组织级遗传证据**（**单一最高价值补强**）：LDSC-SEG / MAGMA 做 BMD 工具在成骨细胞/骨 vs 软骨细胞/软骨的富集；eQTL coloc 比较骨组织 vs 软骨组织 eQTL↔knee-OA 的 PP.H4。把"机制真空"转为"机制旁证"。骨架 `code/40`、`code/41` 已备，仅缺权重/eQTLGen 下载。
7. **F2 量/几何分离条件 MR**：以 vBMD / 髋几何 / 骨面积 GWAS 作第二暴露条件化，分离 height-independent 残差中的"骨量 vs 几何"。这是**核心理论结**（见 §4.2）。

## 4. 深化理论建构的关键要素（核心）

### 4.1 SOS 理论的真实成色（诚实评估）
SOS（系统性成骨设定点）是目前最成形的理论锚点，三条观察碎片（系统性多基因 / 骨–软骨单元 / 腰椎效应最大）已被组织成 6 条预测 + 7 条证伪检验。**但它仍是"结果驱动的后验归纳"**，而非独立预注册理论。其成色可以打：*架构完整、可证伪、但零直接证据、且预测非先验*。

### 4.2 必须升级的五个理论环节
- **K-a · 把"对立终点"新意降级、把"三角联合+位点特异+定量分解"升级为真实增量**（113 已核验并落地 L36/L82）："opposing endpoints" 概念零新意（Foss 1972 起 40+ 年）；真实增量是*同一工具集三角联合估计 + 10 位点特异 + size/mass 定量分解*。稿内已改，需确认不回退。
- **K-b · 核心理论结 = 骨量 vs 几何（F2），不是"机制真空"**。当前 height-independent 残差 67–94% 在定义上就是 mass/geometry 的混合体（身高不投影骨横断面）。**理论前沿不是"有没有机制"，而是"残差中骨量占多少、几何占多少"**。应把 F2 从局限提升为研究纲领支点。
- **K-c · 最强可得的理论推论被低估**：阳性对照 BMD→fracture 仅衰减 −1.7~−3.0%（height-transparent），而 OA 衰减 9.5–33.2% → 因果量在生物学上**异于骨尺寸**。这支持"非尺寸的骨生物学"（骨形成程序 *或* 骨改建/几何程序，二者皆非尺寸），比单纯主张"骨形成"更精确。稿内应明示此推论。
- **K-d · coloc null 的优雅重构**：31/31 无单 SNP 共定位 + 共享基因组富集于 WNT/TGF-β/BMP/SMAD 通路 → 机制是**多基因通路级程序**，非单效应器。这是机制中心论点的优雅落点，F3/F4 是决定性检验。
- **K-e · 不对称性的诚实双陈述**（101 K3）："反向 null"与 SOS 预测*一致*，但功效仅 0.14–0.26，故其*支持*而非*证据*。不得用功效替代理论，也不得用理论抹去功效边界。

### 4.3 理论建构的"可证伪阶梯"应前移
当前 P1–P6/F1–F7 藏在 Table S11（补充材料）。这是稿件的**最强理论资产**，却埋在补充里。建议：
- 主文 §4 增设 **"Biological interpretation and the Systemic Osteogenic Set-point"** 小节，配 SOS 因果链图（图 3 已是概念图，可强化）；
- 把**预测–证伪阶梯**以紧凑表入主文（或至少 Highlights/Graphical Abstract 显式承载"6 predictions, 5 falsifying tests"）；
- F5 标为"首选后续检验"并明说其成本最低、判别力最高。
