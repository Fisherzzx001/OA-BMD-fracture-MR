## 总体判断（开门见山）

这是一篇**诚实度与方法学密度都显著高于同类 MR 稿件**的工作：阳性对照、MRlap、MVMR-size 分解、Steiger、coloc 功效自陈、工具流失分解、与 Hartley 的量级调和，几乎把审稿人能问的都前置回答了。第八轮的 P0/P1/P2 诚实化修改确已到位。

## Editor · 主编预筛（OAC desk screen）

**初筛评分：7.0 / 10 —— 放行进入外审，但需一轮 major revision，不建议以现状态直接送审。**

- **摘要五要素**：背景/问题/方法/结果/意义完整。方法学要素（IVW/Egger/WM/PRESSO/LOO + 阳性对照）交代清楚。

## Reviewer 1 · 理论贡献质询师

**审查要点：核心概念清晰度 / 与现有理论的实质对话 / 去掉这篇论文领域会少什么。**

亮点先记：论文给出了可检验的三个硬增量——(1) 10 位点 BMD→OA 因果图，(2) size/mass 的定量分解（9.5–33.2%），(3) 内部阳性对照校准。这些是真实的领域增益。问题出在理论包装 SOS 上。

**致命漏洞 1：SOS 是一个"可伸缩框架"，理论增量存疑。**
6 个预测里，作者自认只有 P1（对立端点）、P4（size 可分）有实质支持；P2/P3 明说"directionally consistent but not discriminating"（L88/L90），P6 被降级为量级命题（L84），而 5 个伪证检验 F1–F5 全是"pre-registered rather than performed"（L90）。一个以**未执行的检验**为支撑、且大部分预测不具鉴别力的具名构念，很难承担"理论贡献"之重。**去掉 SOS 命名，论文的三个硬增量一个不少**——说明 SOS 目前是叙事包装而非理论本体。
→ 深化方向：把 SOS 从"框架"降格为"解释性假说"，P/F 装置收缩到仅保留有鉴别力的 P1/P4/F1/F2；或补一个**用现有数据就能做**的鉴别性检验（例：按位点机械负荷/骨赘倾向分层，看 BMD→OA 是否向高骨赘倾向位点集中），让 SOS 至少被现有数据检验一次。

**致命漏洞 2："bone-forming set-point" 与 "bone-size/shape set-point" 未分离。**
height 只是 size 的粗糙代理（不含骨宽/几何/形态）。9.5–33.2% 是 size 归因的下界，"67–91% independent of the height–size pathway"被当作 mass-attributable 的上界，依赖 height≈size 的强假设。论文没有建立"这是骨**形成**而非骨**尺寸/形态**"这一理论断言（F2 未做）。
→ 深化方向：把 67–91% 严格表述为 "height-**independent**"，明确其不等于 "mass"；并引 bone-geometry 证据（Faber [35] 已引）做定性支撑，而非让读者自行把 height-independent 误读为 bone-forming。

**致命漏洞 3："opposing endpoints" 的新意被高估。**
fracture-protective 与 OA-risk 的对立，本质是已知的 BMD–fracture 负相关与 BMD–OA 正相关的**因果版重述**。真正新的是"同一遗传 profile 在两端点对立"的**联合估计**，而非这个概念本身。
→ 深化方向：把贡献明确锚定在"三角联合估计 + 位点特异性 + 定量分解"三个可检验增量，而不是"set-point 解释了悖论"这种概念叙事。

## Reviewer 3 · 文献对话审查专家

**Research Gap 推导**（L36 三 gap：位点少 / 单一定义 / 三角未联合）基本自洽、真实存在。Hartley 调和（L86/L94）异常充分，是优点。但有四处需处理：

1. **"first" 创新声明高风险（L92）**："This is the first direct MR test of OA→any-fracture."——这是典型的"伪创新"触发点。若存在 2023–2025 的 OA→fracture 或 OA→osteoporosis→fracture MR，该声明即被反证。**必改：系统检索确认，或软化为 "to our knowledge, among the first direct MR tests"。**
2. **疑似误引/弱引（L32）**：以 [31]（Tong 2025，OA→踝足疾病）支撑"other joint-specific MR analyses of OA report a similar cautionary pattern"——该文主题与 BMD→OA 的关节特异性无关，疑为凑引。**必改：更换为真正讨论 BMD–OA 关节特异性 MR 的文献，或删除该句引用。**
3. **遗漏核查**：BMD→OA 的 MR 文献需再确认 2023–2026 无新的大样本研究被漏（Funck-Brentano 2019 [36]、Hackinger [4]、Zhou [5] 已引）。OAC 审稿人必查，建议补一轮检索。
4. **Hartley 调和篇幅**（L86 单段 400+ 词，L94 再重复）：诚实但冗长，可压缩约 1/3 而不损信息量，避免"过度防御"的审稿印象。

## Reviewer 2 · 方法论审查员（透明度整改清单，标注必改/建议改）

**必改：**

1. **MRlap 的方向性声明存在逻辑跳跃（L50 / L70 / L72 / Fig.10）。** 稿件称"MRlap moved every estimate further from the null (median 20%)，**so the primary estimates are conservative with respect to overlap**"。但 MRlap 合并了**两种方向可能相反的校正**：winner's-curse 校正使比值估计偏向零、其纠正使估计**离零更远**；而 participant-overlap 校正对**同号 r_g 对**（BMD→fracture r_g=−0.53、BMD→OA r_g=+0.14~0.19，Table 2）应使估计**偏向零**。把"离零更远"整体归因于 overlap，并推出"对 overlap 保守"，缺乏依据——若 overlap 分量实际指向零，则主估计对 overlap 是**过度（anti-conservative）**，摘要 L24 对 overlap 的 reassurance 会被误读。**必改：拆分报告 overlap 与 winner's-curse 两种校正各自的方向与量级，删除或改写 "conservative with respect to overlap" 的推论。**（建议对照沉积 MRlap 输出的分量核验。）
2. **femoral-head 位点排除理由不成立（L48）。** 以"它是 Foss & Byers 1972 参考位点，非 regional 暴露"排除股骨头 BMD——但股骨头正是区域位点、且是与 OA 最相关的解剖部位；用"它是历史参考位点"作为排除理由近乎倒置（那更像是**应该纳入**的理由）。排除历史上最核心的 OA 相关 BMD 位点，需要原则性依据（如独立 QC、不同遗传架构、与 10 个入选位点不可比），否则有"避开可能不利的位点"之嫌。**必改：给出原则性理由，或补入 femor-head 分析。**
3. **Effect-scale reconstruction 叙事循环（L52）。** "re-standardised ... using the verified per-site N" 又 "confirmed ... already on the true-N scale ... no post-hoc rescaling applied" —— 表述自相循环，易被读为数据口径不清。**必改：改为断言式一句——"沉积的 β/SE 已处于 N=31,873 的 SD 尺度（由闭式 SE=1/√[2Nf(1−f)] 在 0.1% 内验证）；源数据中的 N=400,000 为文档标注，未施加任何数值变换。"** 并确保沉积数据版本与此一致。

**建议改：**

4. **5/10 BMD 位点进入 MR 的选择逻辑（L48）。** arms/femoral neck/lumbar/legs/total 因"strict clumping completed"入选，其余 5 个因"1000G EUR panel unavailable"推迟——这是**数据可用性驱动**而非预设生物学标准的选择；"positive in all five sites" 的位点特异性结论基于非随机子集。建议说明这 5 个是否为预设的 canonical DXA 位点，并在摘要/结论把位点特异性限定为 "five analysed sites"。
5. **MR-Egger 功率（L64 / L70）。** Egger intercept p>0.24 只表示未检出方向性 pleiotropy，16–31 SNP 下功率有限，≠无 pleiotropy。建议加一句限定。
6. **positive control 的"干净"形象被高估（L62 vs Table 3 脚注 L182）。** 正文 L62 只说 total-body 的 Egger intercept null（p=0.558），但 **femoral-neck→fracture 的 Egger intercept 显著（p=0.018）**（Table 3 L172、脚注 L182）——这是 directional pleiotropy 迹象，却未在正文点明。建议在正文明确，否则阳性对照的校准力被高估。
