## 0. 关于"真实 AIGC 检测基线"——先说清能做什么、不能做什么

因此基线采用**形式化代理评分**：输入正是检测器所依赖的表层信号，权重透明、可复核、可替换为真值。
若后续拿到任一商业 key，把 `code/134` 的 `score()` 换成 API 返回即可，其余流程不变。

### 评分口径（8 项，满分 100，越高越像 AI）

信号：em dash 密度 / 加粗密度 / burstiness(CV) / 句首小品词 / AI 高发词 / **句间**分号 / 被动语态偏离 / MATTR。

两处口径我做了修正，因为初版会误判学术文本：
1. **词汇多样性改用 MATTR（窗口 100 词）而非 TTR**。TTR 随文本长度单调下降，5384 词稿件 TTR=0.257 属必然，用它评分等于惩罚长文本。MATTR=0.727，落在学术英文正常区 0.70–0.80。
2. **分号只罚"句间分号"，列举性分号不计**。MR 论文并列多个 β/p 值时用分号分隔是规范写法（避免逗号歧义）。
3. **AI 词表剔除 `robust`/`robustness`** —— `pleiotropy-robust estimators` 是 MR 领域标准术语。
