## ① §2 效应尺度校正：删除「Z 比=1 验证 K」的误导、改为 SE 比值推导

### 审稿人批评（R2 必改 1）
> 「log-odds 的 Z 恒等于 linear-probability 的 Z（两者都等于 β_LP/SE_LP），与 K 取何值无关。因此这个 Z 比=1 在数学上是**恒等式**，不提供任何关于 K 的信息；K(1−K) 的真实来源是 **SE 比值**，不是 Z 比。把恒等式当『39 SNP 验证』的卖点是呈现误导。」

### 独立验证（trust-but-verify，不盲信审稿结论）
- **一手产物**：`code/output/genetics/_g6_k_estimation.csv`（39 SNP，18 列），由 `code/_probe_g6b.py` 生成；推导链在 `code/21_mr_corrected_N.py` 文件头 28–48 行与 `code/187_sensitivity_table.py` 常量区。
- **独立重算**（本轮 Python，直接读 CSV，不经任何稿件/脚本结论）：
  | 量 | 重算值 | 稿件值 | 一致 |
  |---|---|---|---|
  | median K(1−K) | 0.087082 | 0.0871 | ✓ |
  | IQR | 0.083465–0.088120 | 0.0835–0.0881（S17） | ✓ |
  | 隐含 K | 0.0964 | K=0.0964 | ✓ |
  | 1/√[K(1−K)] | 3.3887 | 3.389 | ✓ |
  | \|Z_true/Z_mun\| | 1.000000000000 (SD 5.28e-14) | 1.000000 (SD 5×10⁻¹⁴) | ✓ |
- **关键数学检验（c-scaling 不变性）**：把 deposited `beta_true` 与 `se_true` 同乘常数 c，重算 Z 比与 K(1−K)：
  | c | max\|Z_c/Z_orig − 1\| | median K(1−K) | 因子 |
  |---|---|---|---|
  | 1.0 | 0 | 0.087082 | 3.3887 |
  | 2.0 | **0**（完全不变） | 0.021770 | 6.7774 |
  | 0.5 | **0**（完全不变） | 0.348328 | 1.6944 |
  → Z 比对任意尺度缩放恒为 1，**确实不携带 K 信息**，审稿人 R2 批评成立。
- **恒等式验证**：`Kc ≡ (SE_munged/SE_true)²`，逐 SNP 最大偏差 **4.163e-17**（机器精度）→ **K 完全由 SE 比值决定**。
- 结论：**数值全部正确，错的是「验证方式」的呈现**。整改只改表述，不动任何数字。
