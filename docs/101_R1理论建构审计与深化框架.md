## 3. 深化理论建构的 11 个关键因素（K1–K11）

> 这是"全面的深化理论建构"的清单。K1–K4 是**理论内核**，K5–K8 是**机制与表型锚定**，K9–K11 是**可检验性与完整性**。

**K1 · 单一假设、对立终点后果（opposing-endpoint）**
不要分别解释"护骨折"和"致 OA"。用**一个**假设解释两者：同一骨形成程序在**整体骨强度**端点是保护性、在**关节（骨-软骨单元）**端点是致病性。这是把"悖论"转为"预测"的关键一步。

**K2 · 把部位梯度升为系统性 vs 力学的判别器（理论的最锐利判别）**
若机制是**局部力学负荷**，则负重/关节邻近位点（股骨颈）效应应最大。数据相反：腰椎 +0.028（最大、且最不被身高解释）> 上肢 +0.022 > 股骨颈 +0.017（最小）。→ **支持系统性，不支持局部力学**。这是理论做出、且被数据**通过**的判别性预测（须附诚实限定：位点间差异在抽样误差内，未正式检验）。

**K3 · 不对称性从"功效伪影"升级为"体质性预测"（R1-2 的核心修复）**
设定点由 germline 变异**在受孕时固定**、自发育起终身作用；OA 是**晚年、局部、力学放大**的组织失败。局部关节病不能回溯性地移动终身系统性设定点；且 OA 对骨的影响是**局部的**（关节周软骨下骨硬化），不会被远隔部位（腰椎、上肢）的 areal BMD 捕获。→ **不对称是理论预测的**。功效不足是**附加**限制，不是解释本身。两条都要写。

**K4 · coloc null 从"无信息"升为"被预测"（把 null 变成理论证据）**
若设定点是**弥散多基因程序**，则**不该**有任何单一位点显示 BMD–OA 共定位。0/31 达 PP.H4≥0.8，且功效界显示即使最强位点也需 ~5×10⁷ 样本（42× 现有）。→ 在理论下该 null **是预测的实现**，而非"测不出所以不知道"。

**K5 · 骨-软骨单元作为机制载体（已有 [27–30]，需与 SOS 对接）**
软骨下骨 MSC 的 TGF-β 活化程序 → 异位骨形成/骨赘 + 血管生成 → 牵拉上方软骨（Zhen 2013）；WNT/β-catenin 与 TGF-β/BMP 串扰（Findlay 2016、Goldring 2016）。SOS 理论主张：系统性设定点**经此 compartment** 表达为 OA。

**K6 · "骨赘为主增生型 OA"作为表型锚点（当前完全缺失，高价值）**
Nevitt & Felson 2020（*Osteoarthritis Cartilage* 28:1151–1153, doi:10.1016/j.joca.2020.05.006, PMID 32417559）：*"high systemic BMD is associated specifically with an **osteophyte-predominant hypertrophic phenotype** of ROA"*。
Hardcastle 2014（*Arthritis Rheumatol* 66:2429–39）：**骨赘–附着点骨化–高骨量"骨形成三联"**。
→ 这把"骨形成程序"从抽象机制落到**可测量的放射学表型**，并使理论可被表型分层检验（F5）。**这是目前最值得补的一条。**

**K7 · 关节部位特异性通路优势（hip vs knee 逆转）**
不同关节的 OA **主导通路**不同：膝 OA 更受系统性/代谢性骨形成通路支配 → BMD 升风险；髋 OA 更受形态学/力学通路支配（cam 形态、FAI、髋形状）→ 效应逆转或衰减。佐证：Faber 2024（髋形状 → 髋**骨折**，但**不**→ 髋 OA）。→ 上升为可检验命题（F1）。

**K8 · areal BMD 复合表型与可识别性边界（与 99e 合并）**
aBMD=BMC/面积，混有骨量与尺寸。MVMR 只证明 ≈79–90% **不被身高解释**；其内部的量/尺寸拆分**未被识别**。→ 必须写明"骨量份额是上界"，分离需 vBMD/髋几何作第二暴露（F2）。

**K9 · 可证伪后续检验清单（顶刊理论贡献的硬通货）**
见 §5 的 F1–F5。没有这个，论文仍是"描述 + 猜测"。

**K10 · 与镜像先例/竞争者的正面文献对话**
Hartley 2022（双向、LCV 直接作用）、Funck-Brentano 2019（FN-BMD→膝/髋 OA 因果）、Zhou 2025（髋 OA 负向）、Hackinger 2017。特别是 Hartley 的**双向性**与本文**单向性**的冲突必须直面。

**K11 · 因果语言与理论支撑对齐**
有了 SOS 理论 + 5/6 预测被支持，"causal" 领衔才真正有理论支撑；但仍须保留限定（随机效应 2/5、重叠未完全排除、功效边界）。理论**支撑**因果语言，不**豁免**限定。

## 4. 统一理论：系统性成骨设定点（SOS）

### 4.1 核心命题（一句话）
> 常见遗传变异设定了一个**终身、系统性的骨形成设定点**（可从任一部位 areal BMD 读出）。该设定点具有**对立终点后果**：在整体骨强度端点是**保护性**的（护骨折），在关节端点是**致病性**的（经骨-软骨单元的软骨下骨形成/骨赘与生化串扰升高 OA 风险）。

### 4.2 机制通路
```
        [germline 变异 → 系统性骨形成设定点 (aBMD)]
                          │
        ┌─────────────────┴─────────────────┐
   整体骨强度端点                       关节端点（骨-软骨单元）
   骨量/强度↑                     软骨下骨形成↑、硬化、骨赘
   → 骨折风险↓                    + TGF-β/WNT/BMP 生化串扰
   （阳性对照 OR 1.42）            → 软骨退化 → OA 风险↑
        └─────────────────┬─────────────────┘
                    对立后果，单一原因
```

### 4.3 六条预测与本文判定

| # | 预测 | 本文证据 | 判定 |
|---|---|---|---|
| **P1** 对立终点 | 同一 BMD 升高谱系：护骨折 + 致 OA | 阳性对照 OR 1.42；BMD→OA 5/5 正 | ✅ 支持 |
| **P2** 系统性而非局部力学 | OA 效应不应在负重/关节邻近位点最大；非负重/中轴位点应≥股骨颈 | 腰椎 +0.028（最大）> 上肢 +0.022 > 股骨颈 +0.017（最小）；腰椎受身高解释最少 | ✅ 支持（判别性；差异在抽样误差内，未正式检验） |
| **P3** 弥散多基因 | 无单一位点 BMD–OA 共定位 | 0/31 PP.H4≥0.8；最强位点也需 ~5×10⁷ 样本 | ✅ 支持（null 为预测实现） |
| **P4** 尺寸为可分离的部分分量 | 身高校正部分衰减 OA 效应，且**不**衰减骨折效应 | OA 衰减 9.5–21.2%；fracture −2.8%（mass-transparent） | ✅ 支持（残差量/尺寸未识别） |
| **P5** 不对称是体质性的 | 反向（OA→BMD/fracture）应为 null，因局部晚发病不能移动终身系统设定点，且 OA 的骨效应是局部的 | 反向 null（power 0.14–0.26） | ⚠️ 方向一致 + 功效不足（**两者并列陈述，不得以功效替代理论**） |
| **P6** 部位通路优势 | 效应方向随关节主导通路而变：膝（系统性/代谢）正、髋（形态/力学）逆转或衰减 | 本文膝正；Zhou 髋负；Faber 髋形状→骨折非 OA | ⚠️ 间接一致（未在髋 OA 上直接检验→F1） |

**净判定**：6 条预测中 **4 条明确支持、2 条方向一致但未完全检验**。这已足以把论文从"描述"提升为"有理论、有预测、有边界"。

## 7. 诚实边界（必须写入 Limitations）

1. SOS 理论是**由本文遗传架构 + 已发表生物学推断**的，非直接测量；BMD 全部为 areal DXA，不分辨软骨下骨微结构/转换。
2. P2 的位点间差异**在抽样误差内**，未做负重 vs 非负重的正式检验——不得表述为已证。
3. P5 方向一致但功效仅 0.14–0.26，不能排除中等效应；理论预测与功效限制**并列**。
4. Hartley 2022 报告**双向**效应，与本文单向结论存在张力；差异来源未在本设计中裁定。
5. 组织富集/eQTL coloc（F3/F4）**未执行**，故"骨驱动"仍为假说而非已验证。
