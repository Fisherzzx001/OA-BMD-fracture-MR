## Reviewer 1 · 理论贡献质询师

**视角**：顶刊理论审稿人，厌恶现象描述堆砌。

### 三个最致命的理论漏洞
1. **核心构念 SOS 是「假说」而非「被证实的理论」，却几乎与研究发现同义反复**（L93）。SOS 被操作化为「可读作 areal BMD 的系统性骨形成 set-point」，而论文自己承认 areal BMD 是 composite、仪器估计的是 composite 而非 volumetric density，故 SOS「directionally supported but quantitatively untested without F2」。即：用 SOS 解释反差端点 → SOS 又由同一 composite 支撑 → 解释力停在观察本身。深度理论松动点：假说自洽但未独立于它要解释的现象获得证据。
2. **判别性预测 P4 / 决定性检验 F2 未执行**（L95, L99）：「67–91% 与身高无关且非 BMI 介导」是**阴性/未定结果**（不能归为骨量），不是阳性理论贡献。论文把最锋利的理论主张（mass-vs-size 分解）建立在一个未执行的检验上，理论贡献当前是「提出了一个可被 F2 证伪的框架」，而非「回答了 mass 还是 size」。
3. **P6 从方向型退为量级型**（L89, L95）：因髋部证据自相矛盾（Zhou 保护 [10] vs Hartley/Funck-Brentano 有害 [12,34]），预注册方向型判据被改写为合取量级判据。预注册偏离已披露（Table S11/F1），但削弱「site-pathway dominance」预测，使理论骨架少一根支柱。

### 深化理论建构的可能方向
- 把 F2（volumetric/size 分解）从「prospective」提升为「本研究可部分执行的代理」：例如用 UKB 的 total-body vs regional BMD 的遗传相关结构近似 geometry，或引用 Faber 2025 [28] 髋形 GWAS 做外部三角。当前只说「F2 是 areal 数据测不了的」——可补一句「可用 regional-BMD 遗传相关矩阵近似，列为下一步」。
- 把 SOS 与已建立的「bone-bar / osteophyte-bone-forming triad」[39] 显式对接，而非仅在 L93 一句带过；这能把假说锚进既有骨生物学文献，提升理论对话密度。

**R1 评分：7.5 / 10**（贡献真实但解释层未独立证成；框架价值高于当前证据价值。）

## Reviewer 2 · 方法论审查员（标尺：STROBE-MR 20 项）

**视角**：方法学洁癖，评透明度。

### 必改（Blocking-level for a top journal）
1. **样本重叠未定量，仅用 Burgess 公式 + r_g 上界**（L55, L73, L99）。所有对共享 UKB 参与者，这是两样本假设的核心威胁。论文给的是「overlap bias ≤2.6%（BMD→OA）/ ≤12%（BMD→fracture）」**上界**，但 Burgess 公式依赖重叠比例本身。STROBE-MR 透明度期望：给出**各 GWAS 的实际 UKB 参与者数 / 两两重叠比例**，或至少每个来源 GWAS 的 UKB N（BMD 31,873 已知；OA_knee ≈1.21M、OA_selfrep 462,933、fracture 264,973 已知，但其中 UKB 占比未给）。这是本文最该补的透明度项——MRlap 也需实际重叠比例，文中未明示其输入。
2. **效应尺度重建（L57）虽巧妙且自验证，但属非常规操作，需更醒目的方法学位置**。|Z 比|=1.000000 的内部验证很强，但 K=0.0964 仅由 39 个同时含 deposited log-odds 与重建 Z 的 SNP 推出。建议 Discussion 或 Methods 补一句「该重建的敏感性：若 K 估计偏误 ±X%，OR 缩放偏误为…」，给出不确定性区间（目前只有点估计 + Audit_Trail 指针）。

### 建议改（非阻塞）
3. **随机效应显著数（2/5）的呈现**（L27, L69, L99）：「we base the causal reading on estimator concordance rather than fixed-effect p-values」是诚实且可辩护的，但主编/方法审稿人会认为在「hedge」显著性。建议 Results 明确给「固定效应 5/5、乘性随机效应 2/5、加性 D-L 随机效应 3/5（含 arms）」三联表，让读者自判，避免「rests on concordance」被读成回避。
4. **MR-PRESSO 9/10 显著**（L75）：已说明属复杂性状 MR 普遍水平且未反转方向，处理得当；建议补「 outlier 移除后效应量变化幅度」（目前只说「four of five strengthening」）以增强透明度。
5. **共定位阈值 0.799 vs 0.8**（L79, L186）：rs11228269 仅差 0.0006，建议补一句敏感性（如阈值放宽至 0.7 时叙事是否变），防审稿人挑战边界。
6. **Steiger 反向非显著的正确解读**（L73）：已明确「非证据 BMD 驱动」，无误读，保留。

## Reviewer 4 · 逻辑链条审查师

**视角**：只审论证结构自洽，不审领域。

### 逻辑链条（顺向）
观测悖论（高 BMD↔OA 却保护骨折）→ 基因组学可分离 → LDSC（OA-BMD 正、fracture-BMD 负）→ MR（BMD→OA 5/5 正、BMD→fracture 保护=阳性对照）→ 多稳健估计量一致 → 因果解读「BMD 升 OA」→ 身高分解（9.5–33.2% 衰减，残差 67–91% 非身高非 BMI）→ SOS 假说 → 反向 null → 结论。主链基本顺滑。

### 断裂点 / 弱支撑 / 跳跃
1. **【断裂·最严重】因果动词强于证据基**（Title L1 / Abstract L27 / Conclusion L101 vs Results L69）。标题与摘要说「raises knee-OA risk」「protected against fracture」，但随机效应下 BMD→OA 仅 2/5 显著、I²=68–86%、MR-Egger 截距多非显著（power 有限）。论文在 Results/Discussion 用「on pleiotropy-robust evidence / rests on estimator concordance」补救，但**标题未带此限定**，形成「标题强因果—正文弱证据」的梯度。建议标题/摘要结论三处统一携带「pleiotropy-robust / estimator-concordance」限定，且摘要把「2/5 under random effects」与「5/5 fixed-effect」并置，消除过度推论观感。
2. **【跳跃】SOS 解释层的循环性**（R1 #1 同源）：观察（反差端点）→ SOS（解释）→ SOS 由同一 composite 支撑。逻辑上未独立于现象获得证据；因论文已框为「testable hypothesis」，不致命，但 Discussion 应更明确「SOS 当前是解释框架，非已证机制」。
3. **【弱支撑】L97 的 r_g 与 MR 反差口头调和**：OA×fracture r_g=+0.119 但 OA→fracture MR null，论文用「BMD 介导成分反向运行」口头调和，但**未展示 OA→fracture  conditioning on BMD 的 MVMR** 来证。属断言式调和，建议补一句「该调和未经 MVMR 直接检验（prospective）」或列为局限。
4. **【弱支撑】67–91%「非身高非 BMI → 非骨量」的否定链**（L81, L99）：逻辑有效（非身高、非 BMI ⇒ 残差属其他，可能是 geometry/mass/其他），「not identified as bone mass」是诚实的停止点。保留。
5. **【一致·确认】身高衰减→size confounding 非 null 协变量稀释**（L81）：借 θ_H 直接效应 p≈10⁻¹⁶ 论证，逻辑严密。
6. **【一致·确认】P6 合取量级判据**（L89）：hip 须正且达 knee 量级才 fail P6；within [12] 区间近乎重叠、log 尺度低 27%，Hartley 证 positivity 非 equality。逻辑自洽。

**R4 评分：7.5 / 10**（主链顺；#1 标题-证据梯度是必须修的逻辑错位，#3 口头调和需标注为未检验。）
