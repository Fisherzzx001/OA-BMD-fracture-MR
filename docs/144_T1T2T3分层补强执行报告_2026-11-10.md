## 2. T1 rebuttal 储备（三项实质分析）

### 2.1 T1-C · coloc-SuSiE（code/325）

- **动机**：稿件 P3「0/31 共定位」用的是 coloc.abf（单位点单因果）。若某位点同时含 BMD 与 OA 两个独立信号，abf 会漏检。coloc-SuSiE 允许每性状多个因果信号（sum of single effects）。
- **实现**：纯 Python 读 1000G EUR bed（503 人）算 31 位点窗口（±500 kb）LD；SuSiE IBSS 变分近似（L=2、p1=p2=1e-4）得每 SNP PIP；**可信共定位判定**：两侧 credible set 均可靠（总 PIP≥0.5 且集合大小≤max(20,10% SNP)）且重叠且 shared PIP mass≥0.5。
- **结果（2026-11-10 两轮 bug 修正后的最终版）**：**0/31 真正共定位**。18 位点 BMD 与 OA 各有集中因果信号但可信集不重叠（shared=0，PIP mass≈0）→ 不共定位；13 位点（rs12568930/rs2566755/rs777355/rs10931982/rs4974056/rs6846509/rs1262476/rs3779381/rs6956946/rs17212655/rs876701/rs10048146/rs6040061）OA 侧 PIP 高度弥散（总质量仅 0.00–0.21、credible set 覆盖几乎整个窗口）→ OA 在这些 BMD 位点附近无集中因果信号，非共定位。窗口 SNP 数 93–503（28 个不同值），确认每位点独立分窗。
- **判定**：P3「弥散多基因」在多因果信号方法下**被强化**。该 0/31 结论经受住两轮独立 bug 修正：① PLINK bed 解码曾把 het/homA2 写反（污染 LD），② positional re-scan 曾按染色体而非按位点分窗（同染色体位点共享 SNP 全集，chr1 四位点曾全报 n=1082）——两者均已修正，结论不变。新增防回归门禁 `code/331`（31/31 解码一致+31/31 eaf 吻合 PASS）。注意：仍是窗口内 IBSS 近似，正式 rebuttal 可用 susieR/coloc 5.2.3 复核。
