### 0.2 我们的三个不可替代点（写进 Cover Letter）

1. **对称双库，而非"主库 + 验证库"**。CHARLS 不是 UKB 的附庸验证臂，而是与 UKB 平权的第二臂：两臂使用同一套协调后的病种清单、同一套网络构建流程、同一套推断流程，产出可双向解读的对比结论。
2. **可比性四件套**（见 §5）——直接修复模板论文最被诟病的方法学漏洞，让"平均度的跨国对比"第一次具有统计推断基础。
3. **病因模块假说而非整体复杂度假说**。我们预先假设：中英差异不在"网络有多复杂"，而在"网络由哪类疾病主导"（代谢型 vs 骨-关节型）。这是一个可被数据证伪的、机制导向的假设，比"比较平均度"高一个层次。

## 1. 研究问题与假设

### 1.1 主问题
在校正年龄、性别、BMI 与背景共病流行率后，**中国（CHARLS）与英国（UK Biobank）OA 患者的共病网络结构是否存在系统性差异？若存在，该差异表现为整体复杂度差异，还是模块/病因结构差异？**

### 1.2 预先设定的可检验假设（全部在 OSF 锁定，防止 HARKing）

| 编号 | 假设 | 检验方法 | 若成立的含义 |
|---|---|---|---|
| **H1**（复杂度） | 中、英两国 OA 患者的共病网络平均度均**显著高于**各自匹配的非 OA 对照 | 病例-对照标签置换检验（10,000 次）+ bootstrap 95%CI | OA 是共病聚集的标志，跨人群稳健 |
| **H2**（模块结构） | 中国 OA 网络的**代谢模块**内部连通性（模块内平均度）显著高于英国；英国 OA 网络的**骨-关节-损伤模块**连通性显著高于中国 | 两样本 bootstrap 比较 Δ（模块内平均度）+ FDR | 支持"代谢驱动型 vs 骨-关节型"分型 |
| **H3**（枢纽病） | 中国 OA 网络枢纽节点为代谢性疾病（高血压、糖尿病、血脂异常、中心性肥胖）；英国为骨关节/肌肉骨骼疾病（骨质疏松、背痛、软组织/关节损伤） | 度中心性 Top-5 对比 + 节点级置换检验 + BH-FDR | 锁定可干预的"枢纽靶点" |
| **H4**（双保险/反直觉） | 在 O/E 标准化与等密度稀疏化后，**两国 OA 网络的整体平均度差异不显著**，差异主要存在于模块结构层面 | 跨库 bootstrap 的 Δ 平均度 95%CI 是否包含 0 | **无论成立与否都能写**：成立 → "整体复杂度是 OA 的普遍特征，病因结构才是种族特异的"；不成立 → 直接支持 H1/H2 |

> **方法学伦理说明**：H4 是本方案的"阴性结果保险"。模板论文的最大卖点正是敢把阴性结果放讨论 C 位（"美国骨折患者共病网络 ≈ 非骨折人群"）。我们预先登记 H4，等于预先承诺：无论结果朝向哪边，都不改研究问题。

### 1.3 探索性分析（明确标注为 exploratory，不作因果声称）
- E1：按性别、年龄组（45–59 / 60–69 / ≥70）、BMI 分层重复主分析。
- E2：按城乡（CHARLS）/ Townsend 剥夺指数（UKB）分层，检验"诊疗可及性"对网络结构的修饰作用。
- E3：仅纳入**OA 诊断前已存在**的共病重建网络（时序敏感性分析）。
- E4：CHARLS 2011/2015 血液标志物（hs-CRP、HbA1c、血脂）与代谢模块连通性的关联。

## 2. 设计类型与报告规范

- **设计**：双库（binational）、基于人群的**匹配病例-对照 + 横断面网络分析**，附时序敏感性分析。
- **报告规范**：**STROBE**（病例-对照条目）+ **RECORD**（常规数据/电子健康记录条目）+ 预注册于 OSF。
- **平行原则**：两臂在病种清单、纳入排除、匹配变量、网络构建、推断流程上**完全一致**；仅数据源特异字段（如 ICD-10 vs 自报）在协调表内分别定义。

## 3. 数据来源与样本

| | 英国臂 | 中国臂 |
|---|---|---|
| 数据源 | **UK Biobank**（Application 待提交） | **CHARLS** 2011–2020 五波（免费注册下载） |
| 基线规模 | 502,536（40–69 岁，2006–2010 招募） | 17,708（≥45 岁，2011 基线；2013/2015/2018/2020 随访） |
| OA 来源 | ICD-10（住院 HES，M15–M19）+ 自报（20002）+ 关节置换手术史 | 自报"医生曾诊断关节炎或风湿"（DA007）+ 关节疼痛部位（DA042 系列） |
| 共病来源 | 住院 ICD-10 主/次诊断 + 自报 + 用药 + 初级保健（若获批） | 自报慢病清单（DA007 系列）+ 用药 + 2011/2015 血检 |
| 权重 | 无需（非概率抽样；用协变量调整代替） | **必须使用复杂抽样权重**（家庭+个人权重、分层、PSU） |
| 预计 OA 样本 | 80,000–100,000（宽定义） | 4,000–6,000（45+，宽定义） |

### 3.1 样本量可行性
- **网络稳定性门槛**：经验规则为每个节点至少需要 10–20 个事件。共同节点集约 18 个病种，最低患病率 1% → CHARLS OA 臂 4,000 人时最低频病种约 40 例，**满足**。
- **匹配可行性**：CHARLS 4,000 例 OA，按年龄±1 + 性别 + 波次匹配非 OA 对照，池子约 12,000 人，匹配率预计 >95%。
- **Bootstrap**：参与者级 bootstrap 2,000 次，CHARLS 侧单次重算 18 节点网络耗时 <1 秒，完全可行。

## 4. 【关键决策点】OA 表型的协调：CHARLS 无部位信息的解法

> ⚠️ **这是 B 档相对原方案最大的实施障碍，必须在取数前定死。**

**问题**：CHARLS 仅询问"是否被医生诊断过关节炎或风湿病"，**无膝/髋部位细分**；UK Biobank 可精确到 M17（膝 OA）/M16（髋 OA）。若强行做"膝/髋 OA"，中方无法定义，两臂不可比。

**解法：双轨表型（Dual-track phenotype）**

| 轨道 | 定义 | CHARLS 可实现 | UKB 可实现 | 用途 |
|---|---|---|---|---|
| **主表型 T1：任意部位 OA（all-site OA）** | 医生诊断的关节炎/骨关节炎（排除类风湿关节炎及自身免疫性关节病） | ✅ DA007 自报 | ✅ ICD-10 M15–M19 ∪ 自报 20002 ∪ 关节置换 | **主分析**（样本最大、两臂最对称） |
| **次表型 T2：症状性下肢负重关节 OA（symptomatic lower-limb OA）** | 医生诊断关节炎 **且** 膝或髋部位疼痛/不适 | ✅ DA007 + DA042 部位疼痛（膝/髋） | ✅ M17/M16 ∪ (自报膝/髋 OA) ∪ (OA 诊断 + 膝髋疼痛) | **次要分析 + 部位特异性检验** |
| **敏感性 S1** | UKB 侧分别用 any / 膝 / 髋 OA 重建网络，检验主结论是否随部位改变 | — | ✅ | 回答审稿人"部位是否重要" |

**必须在论文中明示的取舍**：T1 的优势是对称性与样本量，代价是部位异质性（手 OA 与膝 OA 病因不同）。用 T2 与 S1 共同封堵这一质疑，反而使方法学部分比单部位研究更完整。

**排除标准（两臂通用）**：
- 类风湿关节炎、强直性脊柱炎、银屑病关节炎、系统性红斑狼疮、痛风性关节炎（避免炎症性关节病污染）；
- 年龄 <45 岁；
- 恶性肿瘤终末期（共病结构被治疗严重扭曲）；
- 关键变量（年龄、性别、全部共病字段）缺失者（主分析用完整病例；敏感性分析做多重插补）。

## 5. 方法学核心：可比性四件套（本方案的技术卖点）

模板论文把 28 病网络与 19 病网络的平均度直接对比，是审稿人首先会攻击的点。我们用四步锁死：

### ① 共同节点集（Common Node Set, CNS）
只保留两库**均可定义**的病种（预计 16–18 种，见 `02_变量协调映射表`）。两库各按自身数据源定义，但在 CNS 上建网，节点数严格相等。

### ② 边权重标准化：超额共现（O/E）网络
不用原始共现次数（会被各病患病率差异直接驱动），改用：

$$O/E_{ij} = \frac{n \cdot O_{ij}}{n_i \cdot n_j}$$

其中 $O_{ij}$ 为同时患 i、j 的人数，$n_i, n_j$ 为各病人数，$n$ 为该组总人数。
- 对每条边做**置换检验**（10,000 次重排个体）得 P 值；
- **BH-FDR** 校正（α=0.05）；
- 仅保留 **O/E > 1 且 FDR < 0.05** 的边 → 得到"超额共现网络"。

> 这一步把"中国高血压患病率本身就高"这类**背景流行率差异**剥离掉，只留下 OA 人群内部真正的非随机聚集。

### ③ 等密度稀疏化（Equal-density sparsification）
两网保留显著边后边数必不相等 → 取 $K = \min(K_{CHARLS}, K_{UKB})$，各取 O/E 最大的 Top-K 条边。此时两网**密度严格相等**，平均度可直接比较。

### ④ 网络比较的统计推断（分两层）
- **库内（OA vs 对照）**：病例-对照标签置换 10,000 次，构造平均度差异的零分布 → 双侧 P 值；参与者级 bootstrap 2,000 次 → 95%CI。
- **跨库（中国 vs 英国）**：两样本 bootstrap（各自库内重抽样，重算网络指标，取 Δ）→ Δ 平均度的 95%CI；CI 不含 0 判为显著。同时对模块内平均度、度中心性做同样处理并 BH-FDR 校正。
- **网络指标报告清单**：平均度（主）、密度、模块度 Q、中心化指数、平均聚类系数、模块内平均度。**不只报平均度**——这是相对模板论文的硬性升级。

## 6. 统计分析计划（SAP）

### L1 描述与患病率比较
- 加权/未加权基线（年龄、性别、BMI、教育、城乡/TDI、吸烟、饮酒）；中位数(IQR)、频数(%)。
- 组间比较：χ²；期望频数<5 用 Fisher 精确检验；**匹配数据用条件 logistic 回归**。双侧 α=0.05。
- CHARLS 全程使用 `survey` 复杂抽样权重（层化 + PSU + 个人权重）。

### L2 疾病对与三元组合
- 计数规则：某人患 A、B、C 三病 → A-B、A-C、B-C 各计 1 次（与模板论文一致）。
- 按性别分层，报告 Top-10 二元组合、Top-10 三元组合的加权患病率与 O/E 比。
- 仅患病率 >1% 的病种进入网络分析。

### L3 共病网络构建
- 节点 = 病种（节点大小 ∝ 患病率）；边 = 显著超额共现（边宽 ∝ O/E）。
- 按**病因模块**着色：代谢（高血压、糖尿病、血脂异常、肥胖）、骨-关节-损伤（骨质疏松、背痛、颈肩痛、关节损伤/软组织病、椎间盘病）、心血管（冠心病、心衰、卒中）、呼吸（哮喘、COPD）、精神神经（抑郁、痴呆/记忆障碍）、消化/肝肾（肝病、肾病、消化性溃疡）、肿瘤。
- 模块划分在 SAP 中预先固定，**不做数据驱动的社区发现作为主分析**（避免"选择模块以得到想要结果"的质疑）；数据驱动的 Louvain 社区作为敏感性分析。

### L4 推断（见 §5④）

### L5 敏感性分析（预注册 8 项，全部报告）
1. **严格 vs 宽松 OA 定义**（严格 = 住院 ICD 或自报+用药；宽松 = 任一来源）。
2. **完整病例 vs 多重插补**（`mice`，5 个插补集，Rubin 合并）。
3. **加权 vs 未加权**（CHARLS）。
4. **稀疏化阈值**：Top-K、O/E>1.2、O/E>1.5 三档。
5. **仅新发 OA**（UKB 排除基线前诊断；CHARLS 用 2011 无病、后续新发）。
6. **时序网络**：仅纳入 OA 诊断前已存在的共病（E3）。
7. **排除前 2 年诊断的共病**（降低检出偏倚/反向因果）。
8. **按性别分层**（主分析已分层，此处报告交互作用 P 值）。

### 多重比较
所有网络层面的 P 值统一 **BH-FDR** 校正；主假设 H1–H4 报告原始 P 与校正后 P。
