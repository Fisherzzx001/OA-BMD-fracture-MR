## 3. 风险清单与对策

| 风险 | 影响 | 等级 | 对策 |
|---|---|---|---|
| **UKB 申请被拒/延迟** | T0 阻塞 | 中 | 提前 3 月提交；备选 NHANES 替身 |
| **CHARLS 字段编号与协调表不符** | T1 阻塞 | 低 | 已标注 ⚠️，取数时立即核对；不影响设计 |
| **CHARLS 缺骨质疏松字段 → 16 而非 17 节点** | CNS 缩 1 节点 | 低 | 已在 §表 C 注 2 设计为可降级；改用"慢性肌肉骨骼疼痛综合征"作代表 |
| **OA 自报误分类** | 偏倚 | 中 | 双轨表型 + 严格/宽松敏感性 + E2 教育/城乡分层 |
| **中国农村诊断不足** | 网络表观稀疏 | 中 | 讨论中明确声明；分层分析可能本身成为亮点 |
| **跨库表型口径不齐** | 平均度不可比 | **高** | 已用"可比性四件套"在方法学层面解决；CNS 锁死 |
| **被 Ding 2025 类似的快速 follow-up 抢先** | 创新性打折 | 中 | 立即挂 OSF + 预印本；网络结构 + 模块强度是他们的硬空白 |
| **审稿人要求补影像表型（膝 X 线）** | 大改 | 中 | 主分析 any OA 不动；补做次要分析（UKB 影像子集） |
| **审稿人质疑"模块预定义"** | 选择偏倚 | 中 | 在 SAP 中明示；附数据驱动 Louvain 社区作敏感性 |
| **CHARLS 样本量不足（实际 <3,000）** | H1 检验力低 | 中 | 主结果不依赖 CHARLS 单独显著；要求跨库一致方向 |
| **统计审稿人要求 R 代码** | 交付延期 | 低 | Python 版完全可重写为 R（`matchit`+`survey`+`igraph`+`NetworkComparisonTest`），1–2 周 |
