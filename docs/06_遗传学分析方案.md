## 1. 这批数据到底是什么

| 项目 | 结论 |
|---|---|
| 格式 | Neale-lab UKB GWAS 汇总统计量（**无参与者 ID、无 N 列**） |
| 表型 | 11 个 BMD 部位 + 1 个 any-type fracture，每个 ≈597 万 SNP（常染色体 1–22） |
| 列 | chromosome, base_pair_location, effect_allele, other_allele, beta, standard_error, effect_allele_frequency, p_value, rs_id |
| 质量 | λ_gc：BMD 各部位 1.10–1.13（轻微膨胀，UKB 连续性状常态）；骨折 1.04（几乎无膨胀，病例对照正常）。无非法 SE、无极端 EAF、无重复行异常 |

**关键判断**：这是 **OSTEO-GLOBAL 的"组学（遗传学）"支柱**，不是 OA 观察性共病网络要的疾病自报标志。
- OA B 档共病网络管线（`01/03/04/05_*.py`）需要 `charls.csv / ukb.csv` 里的**二值疾病列**（关节炎、高血压、糖尿病……）。
- 本批 GWAS **不能直接喂进那套管线**。它支撑的是一套独立的遗传学分析（MR / 遗传相关 / 富集）。

## 3. 可选分析（按价值/外部依赖排序）

### 方案 A · 遗传相关矩阵（LDSC `rg`，12×12）★推荐首选
- **做什么**：估计 11 个 BMD 部位之间、及 BMD↔骨折之间的成对遗传相关。
- **科学问题**：不同部位 BMD 的遗传架构是否共享？骨密度与骨折的遗传耦合强度如何？→ 直接回答"骨-关节轴"的遗传层面。
- **外部依赖**：EUR 1000G LD 计分文件（~数百 MB–数 GB，需联网下载）。
- **产出**：12×12 rg 矩阵 + 热图 + 显著对列表。

### 方案 B · 孟德尔随机化 MR（BMD → fracture）
- **做什么**：以 BMD 遗传工具变量检验"高骨密度是否因果降低骨折风险"。
- **科学问题**：骨密度→骨折的因果方向（反向 MR 可证伪）。
- **外部依赖**：LD clumping 参考（1000G EUR，plink 格式）+ 各表型有效样本量 N（**源文件无 N 列，需从 UKB 申请记录/Neale 网页补**）。
- **产出**：MR-IVW / MR-Egger / 异质性 / 水平多效性检验。

### 方案 C · 基因集/通路富集（MAGMA / PISCES）
- **做什么**：把显著 SNP 映射到基因与通路（如 Wnt/β-catenin、RANK-RANKL、胶原代谢）。
- **外部依赖**：基因坐标映射 + 注释库。
- **产出**：富集通路表 + 候选基因清单。

### 方案 D · 多效性到 OA（需另取 OA GWAS）
- **做什么**：用本批 BMD 工具变量 MR 到 OA（或反之），检验"骨-关节轴"因果。
- **外部依赖**：**OA GWAS 汇总统计量（需另行获取，如 UKB OA 或 GEFOS/arcOGEN）**。
- 这是与 OA B 档共病网络最直接对话的遗传学桥接，但缺 OA GWAS 输入。

## 4. 与 OA 观察性共病网络的关系（重要）

若你最终目标是 **OA 共病网络 B 档论文**，本批 GWAS **不是**它的输入。该论文要的真实数据是：
- **UKB 观察性字段**：self-reported illness (Field 20002)、 ICD10 hospital (Field 41270/40001)、药物 (Field 20003)、体格测量 (Field 21001/23104) 等 → 生成二值疾病矩阵。
- **CHARLS**：da007 系列自报慢病 + 关节炎条目。
→ 按 `02_变量协调映射表_CHARLSxUKB.md` 回填 `code/data/ukb.csv` 与 `charls.csv`，再 `python run_all.py --real`。

**所以存在两种并行推进路径**：
1. 用本批 GWAS 单独做"组学"支柱（方案 A/B/C）；
2. 另行下载 UKB 观察性字段，把 OA 共病网络跑通。
