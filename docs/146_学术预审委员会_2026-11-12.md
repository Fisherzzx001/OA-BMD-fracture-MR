## 7. Reviewer 1 维度深入：判别内核能否被现有数据判别？

R1 的三个漏洞里，R1-1（概念置换）和 R1-3（机制权重）是**论证/措辞层**，可按下文 §8 改稿处理；**R1-2 是唯一的实质科学问题**，且它是可检验的——不应停在"批评 vs 辩护"，而应让数据裁决。本节给出首个**位点级直接检验**。

### 7.1 内核的精确陈述（先拆成两个可检验分量）

SOS 在 L93/L135 的核心是："**同一组遗传变异**必须在整骨端点降骨折、在关节端点升 OA，符号由单一潜在设定点固定，而非端点特异通路。" 这句话其实含两个强度不同的断言，此前被混为一谈：

| 分量 | 断言 | 可被什么证伪 |
|---|---|---|
| **L1 符号分量**（弱） | 同一批 BMD 工具在两端点的效应倾向反号 | 符号不偏反号（≈随机 50/50） |
| **L2 量级分量**（强，"单一设定点"的判别器） | 两端点效应向量**强反相关**（r→−1），因为同一潜变量按固定比例驱动两端 | 效应量级不相关或弱相关（r≈0） |

**关键逻辑**：L1 反号是 single-set-point 模型与 two-partially-coupled-modules（两个部分耦合模块、净效应相反）模型**共有**的；只有 L2 能把二者分开。论文 L135 声称内核"non-trivial, not a generic correlation"，正是把共有的 L1 当成了判别器——这是 R1-2/C 断点 C 的要害。

### 7.2 现有 31 工具的直接检验（`code/339`，只读、不动任何已报数值）

输入：`BMD_total__fracture.csv` 与 `BMD_total__OA_knee.csv`，同一 31 SNP、beta_e 逐位一致（`code/334` 已验证）。对每 SNP 取 Wald ratio `β_o/β_e`（对齐 BMD 升高等位基因），比较两端点效应向量。

| 检验 | 结果 | 读数 |
|---|---|---|
| 聚合 IVW（已报） | fracture β=−0.3371；OA β=+0.0783 | ✅ 聚合层面端点符号相反 |
| **L1 符号反号** | **22/31 反号，精确二项单尾 p=0.0147**；IVW 权重 73.1% 落在反号组合；骨折保护 25/31、OA 升高 24/31 | ✅ **符号分量成立** |
| **L2 量级反相关** | **Pearson r=−0.156, p=0.403**，bootstrap 95% CI **[−0.451, +0.156]**（跨 0）；Spearman ρ=−0.124, p=0.508 | ❌ **量级分量不成立** |
| 测量误差校正 | 去衰减 r≈−0.190（reliability FX 0.79 / OA 0.85） | 仍弱，远非 −1 |
| 强工具子集（OA 名义 p<0.05, n=16） | r=−0.222, p=0.408；反号 12/16 | 方向在、量级仍不显著 |
| LOO 稳健性 | r∈[−0.206, −0.064]，**31/31 全为负** | 负号稳健但幅度小 |

**判定（预先声明的判据）**：支持"单一设定点"需 L1 **且** L2 同时成立（强反相关、CI 远离 0）。本检验 **L1 成立、L2 不成立** →

> **SOS 内核的符号分量得到支持（22/31 反号，p=0.015；LOO 全负），但"单一潜在设定点强制效应量级成比例反号"的强版本不被支持（r=−0.16, p=0.40）。现有数据支持"两个端点净方向相反"，但不足以判别"是否单一设定点"。符号相反 ≠ 单一设定点。**

这与 R1-2 的判断完全一致：**内核从未被判别**；首次判别的结果是"弱版本成立、强版本未证实"。

### 7.3 这不是推翻论文，而是给它一个诚实且更强的定位

1. **对论文有利的部分**：聚合端点反向（论文主结果）+ 位点级符号反号显著（22/31, p=0.015）+ 73% IVW 权重在反号组合——这些是真实、可复现的"端点方向相反"证据，比单纯两个 MR 点估计更细。
2. **对论文不利但诚实的部分**：论文 L135 把"符号相反"包装成"单一设定点的判别器"是**过度声称**；数据实际上不支持"单一设定点"强版本。若不改，Reviewer 1 一旦自己算这个相关（他完全会），论文的可信度受损。
3. **正确定位**：把 SOS 从"已具备判别式内核的理论"降为"**提出一个尚待判别的内核准则**"，并把 7.4 的两模型比较列为**优先执行的判别检验**。这与论文已有的"set-point core is untested"（L93）诚实表述一致——只是此前没量化。

### 7.4 正式判别方案：单设定点 vs 双耦合模块模型比较（返修执行）

**模型设定**（在同一 31 工具、两端点效应向量上）：

- **M1 单潜在设定点**：存在一个潜因子 L，使第 j 个变异的两端效应 `θ_fx,j = a·L_j`、`θ_oa,j = b·L_j` 且 `a·b<0`。可检验含义：两端点 Wald ratio 向量共线且反号 → **|Pearson r| 应接近 1**（观测误差衰减后仍应显著为负且绝对值大）。
- **M2 双部分耦合模块**：整骨模块与关节模块各有独立变异集，仅通过共享的 BMD 上游部分耦合 → 预测效应向量**弱相关或零相关**，但聚合 IVW 效应可因共享上游而方向相反。

**判别统计**：

1. **主检验**：M1 的 r 应显著且 |r|>0.5。当前 r=−0.156（p=0.40）→ **当前数据偏向 M2**。为给 M1 公平机会，须做**测量误差去衰减 + 工具强度加权**的 r 估计并给 bootstrap CI；当前去衰减 r≈−0.19，仍远达不到 0.5 门槛（见 7.2）。
2. **模型比较**：在层次模型下比较 M1（1 个共享潜因子）与 M2（2 个模块因子 + 耦合参数）的拟合（AIC/BIC 或 LOO-CV）；M1 参数更少，若拟合不劣于 M2 才支持单设定点。当前 r 的量级提示 M2 会以较大边际胜出。
3. **功效诊断**：31 工具、两端点抽样方差已知（reliability 0.79/0.85），可在置零相关下模拟：要检出 r=−0.5 需多少工具？这决定"未判别"是"证据不足"还是"证据反对"。**若 M1 需 >150 工具而当前仅 31，则应明确写为 underpowered discrimination，而非 M1 被否定。**
4. **样本重叠处理**：两 GWAS 共享 UKB，会压缩 r 的独立性；用 block-jackknife 或 MRlap 残差重估，确认 r 的负号不是重叠伪影。

**证据分级写入建议**（替换 L135 的判别内核段）：

> 我们检验了 SOS 的两个可证伪分量。同一 31 个 BMD 工具的端点效应在符号上倾向相反（22/31，二项 p=0.015；IVW 权重 73% 落在反号组合），支持"端点净方向相反"。但效应量级并未强反相关（r=−0.16，p=0.40；去衰减 r≈−0.19），不足以判别"单一设定点"强版本——该模式与两个部分耦合、净效应相反的模块同样相容。故我们将 SOS 的判别内核表述为**尚待判别**（需更大规模工具集或 vBMD 工具），而非已成立（§7, `code/339`）。

**优先后续检验**（与论文 F2/F10 优先项对齐）：
- **F2 体积臂**：真正的 vBMD 工具若使符号对立消失（r→0 或翻正），直接证伪内核——这是最强的单点判别。
- **扩大工具集**：endpoint-specific 工具 + 更严格 clumping 提升 M1/M2 比较功效。
- **跨祖先（F10）**：ancestry-specific 反转会证伪内核（L135 已列此 falsifier）。

### 7.5 对 R1-1 / R1-3 的措辞结论

- **R1-1**（概念置换）：接受批评。L35/L81/L93 必须把 areal BMD 的"临床代理/复合量/设定点读数"三角色拆开——观测层只主张 areal BMD 端点反向（已证），机制层"成骨设定点"明确标注为未证假说，不再用 areal BMD 直接定义设定点（见 §8 改稿 D2）。双膦酸盐 RR 0.71 的论证要反转表述：它证明 areal BMD **不能**区分形成/吸收，因此**不能**把 areal BMD 当作"成骨设定点"的纯净读数——这削弱而非支持等式。
- **R1-3**（机制权重）：接受。保留 `formation-side evidence is indirect` 披露，但把 SOS 从"标题外全部图示（S21/S23）的组织核心"降为"解释性工作假说"；细胞锚点 [47]+自引 [48] 只作示意，不作机制证实。
