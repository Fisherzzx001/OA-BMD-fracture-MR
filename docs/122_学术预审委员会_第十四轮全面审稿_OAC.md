## 【Reviewer 1】理论贡献质询师

### 致命漏洞 1 — SOS 的操作化变量与它要对抗的竞争假说不可分离
L93 定义"Systemic Osteogenic Set-point (SOS)，operationalised as areal BMD"。但同一段你自己承认"if the causal quantity is volumetric density, an areal-BMD estimate is diluted by skeletal size"，L81/L99 又反复强调 67–91% 的残余"not identified as bone mass""resolved only by F2"。

**这意味着：本文的核心理论实体（成骨设定点）是用一个把该实体与其头号竞争解释（骨骼尺寸）混在一起的变量来测量的，而唯一能分离二者的检验 F2 未执行。** 那 P4 "height attenuation 9.5–33.2%" 就不是"尺寸部分被量化"，而只是"身高这个特定代理能解释的部分被量化"——你已经用 ref 35 说明身高既抓不住骨宽度也抓不住几何。一个用错误代理做的上限界，不构成对理论实体的识别。

**深化方向.** 把 SOS 从"areal BMD 读数"降级为"一个关于骨形成速率的潜变量"，并明确写出它的三条竞争操作化（vBMD、骨面积、骨几何）以及为什么当前数据只能给出三者之和。这不需要新数据，只需要把话说对。

### 致命漏洞 2 — P1–P6 标为"derived"，却又被当作 SOS 的支持证据
L95 的标题是 "**Predictions (derived)**"——诚实，但致命：derived = 看见结果之后写出来的。然后 L95 紧接着用 P1 "supported"、P2 "systemic clause supported"、P3 "direction-consistent" 去支撑 SOS。**事后导出的预测通过检验，其证据权重为零**——这在统计学上叫 post-hoc accommodation，不是 prediction。六个"预测"里：P1 是把已知流行病学事实用遗传学重述；P2 的排序条款欠功效（p=0.228）；P3 自认 "non-discriminating"；P5 自认 "consistent but not evidence"；P6 已被弱化；唯一有判别力的 P4 未解决。**六条里零条构成独立证据。**

**深化方向.** 把 P1–P6 的标题从 "Predictions (derived)" 改为 "**Post-hoc consistency checks**"，并在一句之内说明"它们不构成对 SOS 的独立支持，其功能是界定 SOS 的失效空间"。这样才能保住 L95 后面 F1–F7 那套真正预注册的检验（那才是你的资产）。

### 致命漏洞 3 — 机制层完全空白：没有任何"如何从成骨设定点走到关节风险"的可检验链条
L93 引用 ref 27–30（软骨下骨重塑 ↔ 软骨降解）作为背景，然后直接跳到"一个系统性设定点会在骨端保护、在关节端有害"。中间是空的：设定点通过什么介质作用于关节？软骨下骨密度？骨小梁微结构？骨赘形成（ref 34 Hardcastle 的"bone-forming triad"其实已经给了线索——骨赘/附着点骨化/高骨量三者同源）？本文一个都没测，也没把它们写成可被 F1–F7 之外的检验。**ref 34 被引了一次（L93）就没了，而它是唯一能把 SOS 与 OA 的具体表型（骨赘）连起来的文献，放着不用是理论浪费。**

**深化方向.** 把 SOS 拆成两级：L1（系统性成骨倾向 → areal BMD ↑ / 骨折 ↓）、L2（同一倾向 → 软骨下骨硬化 + 骨赘形成 → 关节风险 ↑）。F5（骨赘型 vs 关节间隙狭窄型分层）本来就是 L2 的检验——既然 F5 是"immediate next step"，就在讨论里明确它是 L2 层唯一的现有判别器，而不是笼统地叫"表型分层"。

**去掉这篇论文，领域会少什么？** 答：13×13 r_g 矩阵（10 个 BMD 位点的完整互相关结构，此前最多两位点）与"尺寸份额上限界"（9.5–33.2%）。这是一个**扎实的增量**，不是转型贡献。稿件目前的包装（SOS + P1–P6 + F1–F7 的宏大框架）超出了这块的体量，会招来"框架很大、判别力很小"的批评。**建议降调：把 SOS 明确写成"工作假设与检验议程"，不要写成"理论"。**

## 专项裁定：**"过多 limitation / 过度自我贬损"**

（本条为本项目长期关注点，单列。）

**量化.** 正文（Introduction→Conclusion）约 3,998 词中，限定性/自我否定类措辞共 **45 处**（weak 7、limitation 5、non-significant 5、does not 4、cannot 3、unresolved 3、conservative 3、underpower(ed) 3、does not exclude 2、not read as 2、deferred 2、其余各 1），密度 **≈1.1%**。

**裁定：不是"过多"，不构成过度自我否定。** 在一篇 MR 论文里 1.1% 的限定密度是**偏低**的；且这些限定绝大多数是真实边界（反向欠功效、祖先错配、areal BMD 混淆尺寸、残余未分解），按项目硬约束一条都不该删。

**但存在三种真实的"自我呈现"缺陷，性质与"过度否定"相反：**

1. **重复型自我否定**（L3）：同一条局限说 5 遍（祖先）/6 遍（欠功效），把紧张的词数预算花在复读上。→ **压缩重复，不改内容。**
2. **遗漏型自我贬损**（M5，最严重）：31 位点共定位对照的**骨折臂（9/31、中位 0.153、p=0.0043）**是全文最强的骨侧机制证据，却与 F4 的执行状态一起被整段留在稿外；读者只看到"没有共定位"。**这是把有利于自己的证据当成不存在——比过度自贬更伤论文。**
3. **卖点错位**（Editor）：Highlights 第 4 条把 "non-significant and underpowered" 放在了唯一被单独索引的字段里；而真正的两个卖点（十位点 r_g 矩阵、9/31 vs 0/31 的骨侧共定位分裂）一个没进 Highlights。

**净结论：本文的问题不是"说了太多局限"，而是"重复说局限 + 漏报一条有利证据 + 把 null 当卖点"。**
