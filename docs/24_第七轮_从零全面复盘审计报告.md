## 四、数据卫生问题（不影响稿件，但建议处理）

1. **`mr_results_corrected.csv` 命名误导** —— 实为 1-Mb 敏感性集结果，易被误读为主分析。建议重命名为 `mr_results_1mb_sensitivity.csv`。
2. **`mr_results.csv` 的 MR-Egger 截距 p 未按 N 尺度校正** —— 其 `egger_intercept_se` 仍为原始重建尺度（未除以 3.5426），导致如 BMD_total→fracture 的截距 p 为 0.158 而非正确的 0.558。稿件 Table 3 用的是正确值（来自 AUDIT），故稿件无误；但若外部引用该文件会出错。
3. **投稿包未含图文件** —— `submission_package_v16/` 只有 docx 与 S2/S3 补充材料；18 张图在 `Figures_v17_Nature/` 与 `Figures_Package_v17.zip`，投稿时需单独提交并在 cover letter 中说明。
4. **根目录下散落大量历史遗留文件**（`Submission_Package_v2…v15.zip`、`debug*.py`、`install_*.log`、`smoke_*.R` 等），建议清理后再公开仓库。
