## 2. 方法：为何不直接用官方 ldsc

官方 `bulik/ldsc` 是 **Python 2** 软件，移植到 Python 3 存在**无底洞式**的兼容断层。
实际移植过程中依次遇到的致命问题：

| # | 问题 | 处理 |
|---|---|---|
| 1 | `print` 语句（27 处）、`xrange`（22 处） | 脚本批量转换 |
| 2 | `reduce` 未从 `functools` 导入 | 加导入 |
| 3 | 包内裸导入 `import jackknife` 等 | 改为 `from ldscore import ...` |
| 4 | `ldscore.py` 第 297 行缩进错位 | 手工修 |
| 5 | `munge_sumstats.py` 两处 `try:` 缺 `except`（缩进错乱） | 手工修 |
| 6 | `clean_ignore + flag.keys()`（dict_keys 不可拼接） | 转 list |
| 7 | `cname_translation.values().count()`（dict_values 无 .count） | 转 list |
| 8 | `pd.set_option('precision')` / `delim_whitespace` 在 pandas 2 已移除 | 替换 |
| 9 | Logger 以二进制模式打开日志文件 | 改文本模式 |
| 10 | `traceback.format_exc(ex)`（py3 不接受参数） | 去参数 |
| 11 | munge **无 `--chr/--bp` 参数**，仅按 rsid 匹配 | 绕过 |
| 12 | `parse_dat` 分块读取返回空 → `pd.concat([])` 崩溃 | **放弃移植** |

**决策**：放弃移植，改为**按官方公式原生实现**。公式逐行对照
`ref/ldsc-master/ldscore/regressions.py` 抄录，保证算法等价。

### 2.1 精确公式（对照官方源码）

**h²回归**（`Hsq.weights`, regressions.py L498–535）：
```
c      = h2 * N / M
het_w  = 1 / [2 * (intercept + c * l)²]      ← 注意平方
oc_w   = 1 / l
w      = het_w * oc_w
```

**遗传协方差回归**（`Gencov.weights`, regressions.py L622–677）：
```
a      = N1*h1*l/M + intercept_h1
b      = N2*h2*l/M + intercept_h2
c      = sqrt(N1*N2)*rho_g*l/M + intercept_gencov
het_w  = 1 / (a*b + c²)
w      = het_w / l
```

**标准误**：删除一块 jackknife（官方 `n_blocks=200`）。
解析 WLS 的 SE 会因 SNP 间 LD 相关而**严重低估**，必须用 jackknife。

### 2.2 两个致命细节（踩过坑，必记）

1. **`M` 是"用于估计 LD 计分的 SNP 总数"，不是 LD 得分之和。**
   官方注释原文：*"Number of SNPs used for estimating LD Score (need not equal number of
   SNPs included in the regression)"*，取自 `.l2.M` 文件。
   → 误用 `M = sum(l)` 会让 rg 直接爆掉（曾得到 rg=1.116）。

2. **权重中 `(intercept + c·l)` 必须平方。**
   漏掉平方会导致估计严重有偏（实测 h²_B = 0.184 vs 真值 0.30）。

### 2.3 本实现相对官方的额外保障

| 项 | 官方 ldsc | 本实现 |
|---|---|---|
| 等位基因对齐 | 依赖 `--merge-alleles` 外部文件 | **内置**：以参考表型为基准翻转 z，剔除无法判定的 SNP |
| 回文 SNP（A/T、C/G） | 需外部处理 | **自动剔除**（链方向不可判定） |
| 成对比较的 SNP 集 | 逐对取交集（各格不同） | **12 表型共同交集**（矩阵内各格可比） |
| 依赖 | py2 + bitarray + 外部 LD | 纯 numpy/pandas/scipy |

### 2.4 工具链自检（合成数据，真值已知）

设 h²_A = 0.40、h²_B = 0.30、ρ = 0.60，用真实 LD 参考的 50 万 SNP 生成：

```

估计: h2_A = 0.414 (SE 0.007)    真值 0.40
      h2_B = 0.299 (SE 0.006)    真值 0.30
      gencov = 0.2070            真值 0.2078
      rg = 0.589 (SE 0.013)      真值 0.60
intercept: h2_A = 0.982, h2_B = 1.003, gencov = 0.003   （理论值 1, 1, 0）
✅ 回收成功
```

## 3. 一条重要的数学性质

**rg 与 N、M 无关**：

```
h2_1 = slope1 * M / N1
h2_2 = slope2 * M / N2
gencov = slope_gc * M / sqrt(N1*N2)

rg = gencov / sqrt(h2_1 * h2_2)
   = [slope_gc * M / sqrt(N1N2)] / [sqrt(slope1*slope2) * M / sqrt(N1N2)]
   = slope_gc / sqrt(slope1 * slope2)
```

→ **遗传相关矩阵完全不受 N 列取值影响**。即使 N 是占位值，rg 依然有效。

但 **h² 依赖 N**：LDSC 中只有 `N × h²` 可识别，h² 本身必须外部给定 N。
→ 见 §5。

## 4.8 两样本孟德尔随机化：从相关到因果

描述性 rg 只能说明共享遗传架构，MR 才能指向因果方向。
按 `local-mr-neale-gcst` skill 流程实现（`code/13_mr_analysis.py`，纯 Python 无 R）。

### 方法
- 工具变量：暴露 GWAS 中 `p<5e-8`，**1-Mb 窗口近似 clumping**（每窗口留最显著 SNP）。
  ⚠️ 正式投稿应替换为 **PLINK + 1000G 严格 clump（r²<0.001, 10 Mb）**。
- 匹配键：`chromosome + base_pair_location`（**绝不用 rs_id**）；等位基因按名字对齐，反向则翻转 beta。
- 估计量：IVW（固定效应 + 随机效应）、MR-Egger（截距检验定向多效性）、加权中位数；
  异质性 Cochran Q / I²；Radial 离群剔除（学生化残差 |z|>3）；留一法（LOO）。
- 阳性对照先行：**遗传性高 BMD 应降低骨折风险**。

### 阳性对照（通过）

| | 值 |
|---|---|
| IVW（固定） | β = **−1.194** (SE 0.079), P = 3.7e-51 |
| IVW（随机） | β = −1.194 (SE 0.170), P = 2.4e-12 |
| MR-Egger | β = −1.195, **截距 P = 0.558**（无定向多效性）|
| 加权中位数 | β = −1.391（与 IVW 同号）|
| LOO | β ∈ [−1.29, −1.08]，**符号翻转 0** |

→ 方向（负）与生物学一致，无多效性、无单 SNP 驱动。**管线可信。**

### 主结果：BMD → 膝 OA（因果正向）

| 暴露 | IVW β | P(固定) | P(随机) | Egger 截距 P | 加权中位数 | n_snp |
|---|---|---|---|---|---|---|
| BMD_total | **+0.0819** | 3.9e-10 | 6.2e-3 | 0.810 | +0.068 | 31 |
| BMD_lumbar | **+0.0948** | 1.9e-8 | 1.8e-2 | 0.240 | +0.120 | 22 |
| BMD_arms | **+0.0790** | 9.6e-7 | 5.5e-2 | 0.973 | +0.027 | 17 |
| BMD_leg | **+0.0628** | 2.3e-5 | 9.8e-2 | 0.815 | +0.027 | 24 |
| BMD_femur_neck | **+0.0619** | 3.8e-4 | 4.1e-2 | 0.907 | +0.054 | 26 |

**五项诊断全部支持因果结论**：
1. 5 个部位方向一致为正；
2. Egger 截距全部 P > 0.24 → **无定向水平多效性**；
3. 加权中位数与 IVW 同号；
4. LOO **符号翻转 0** → 无单 SNP 驱动；
5. 与 §4.2 的 rg（+0.12~+0.25）方向一致。

### 反向 MR 与 OA → 骨折

| 方向 | β | P(固定) | 结论 |
|---|---|---|---|
| OA_knee → BMD_total | +0.048 | 0.097 | **不显著** |
| OA_knee → BMD_femur_neck | +0.046 | 0.112 | **不显著** |
| OA_knee → fracture | +0.086 | 0.402 | **不显著** |

→ **反向不成立**，支持因果方向为 **BMD → OA**（而非 OA 导致骨量升高）。
OA 与骨折无因果证据，与 §4.6 的 rg 不显著互相印证。

### 必须诚实报告的局限

- **异质性高**：I² = 67–85%，Q 的 P 均 < 0.001。随机效应 IVW 下 BMD_total /
  femur_neck / lumbar 仍显著（P<0.05），但 **arms（P=0.055）与 leg（P=0.098）仅边缘**。
  论文中应以**随机效应为主结果**，固定效应作敏感性。
- **工具变量数偏少**（17–31 个），且为 1-Mb 近似 clumping；正式分析需严格 clump + MR-PRESSO。
- **效应量绝对值不可直接引用**：暴露 beta 由 Z/N/MAF 重构（§5），绝对尺度依赖 N 列；
  **方向与显著性可靠，绝对值待 N 核定后重算**。

## 5. ⚠️ 引用 h² 前必须先核实 N

本批 10 个 BMD 文件的 **N 列 = 400,000**，但其信号强度（平均 χ² ≈ 1.17–1.25，
GWS 位点 170–514 个）**只相当于 3 万量级的样本**，远弱于 N=40 万应有的水平
（真实 eBMD GWAS 通常有数千个 GWS 位点、平均 χ² > 1.5）。

**最可能的解释**：这些 N 列是占位值；真实样本量接近 **UKB DXA 亚组（约 3.2 万）**。

验证性推算：若真实 N ≈ 35,000，则
```
h2_true = h2_reported × (400,000 / 35,000) ≈ 0.0206 × 11.4 ≈ 0.235
```
与文献报道的 eBMD SNP-h²（0.20–0.25）**吻合**。

**处置**：
- **rg / 遗传相关矩阵**：可直接引用（§3 已证明与 N 无关，§4.7 已实证）。
- **h²**：在核实各表型真实 N 之前，**不得写入论文**。
  需从原始来源（Neale-lab manifest / GWAS Catalog / IEU OpenGWAS）取回每个表型的 N。
