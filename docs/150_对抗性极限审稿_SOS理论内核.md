## 1. R1 三条逐条核验

### 1.1 L93 "SOS kernel is not supported by the data" —— 属实，但稿件漏报了最强反证（F6）

- **属实性**：L93 原文"its discriminating kernel ... is not supported by the data"确实存在；作者自己也承认 coloc split 功效受限、ρ̂ 含 0、PCA 中立。所以 R1 第 1 条字面成立。
- **但这是选择性自贬**：同一条 L93 段落把三个弱/中立证据列成 SOS 的"资产负债表"，却**略去了唯一一个方法学扎实、功效充足的判别检验 F6**。`code/124` 给出的 F6 结果：跨 5 个位点的 BMD→knee-OA per-SD 效应同质性 **Q_exact=6.92, 4 df, p=0.14, τ²=0**，且作者正确指出"naive Q 因共享工具而反保守、exact Q 有效"。这是一个**真正支持**"单设定点可读于任一部位"的检验，且处理共享工具协方差、Cholesky 交叉验证，方法无可挑剔。
- **结论**：说 SOS"无任何支撑"是作者对自己稿件的过度自我否定（与 `code/122` 揭示的"去除过度自我否定"回路同源）。准确表述应是：**判别核在最强检验（F6）上未被推翻、在弱检验上不确定、在 coloc 上功效不足**。

### 1.2 ρ̂=−0.13（95%CI −0.58~+0.40 含 0）—— 数字属实，但 R1 误读含义

- **数字属实**：`code/340` 的 M2 自由 ρ 拟合给出 ρ̂=−0.13，profile 95%CI [−0.58, +0.40]，确实跨 0。
- **方向被误读**：点估计 **−0.13 是负的**，正是 set-point 预测的方向（同一工具对骨折与 OA 的效应应负相关）。区间含 0 只说明"弱耦合"与"近独立"无法区分，**并不反驳** set-point。
- **稻草人问题**：M1 固定 ρ=−1 且 τ_oa→0（最极端子例）。但一个真实的单设定点，只要端点各有噪声，ρ 必然落在 (−1, 0)（例如 −0.4~−0.5），**永远不会等于 −1**。所以"拒绝 ρ=−1"在理论上近乎同义反复——没人主张 ρ=−1 且零端点噪声。数据（ρ̂ 含 −0.4~−0.5 量级）与一个**中等耦合的真实单设定点完全相容**。
- **该分析本就被设计为"非结果"**：`code/340` 注释明写"若 CI 含 0，则'近独立'与'弱耦合'均不可排除——报告为'耦合强度未定位'"，且功效分析显示 31 工具不足以定位 ρ。所以正确解读是**功效不足导致不确定**，而非"证据反设 point"。
- **结论**：R1 把"区间含 0"当成"非证据"是过度解读；稿件自己的"rejecting the strict ρ=−1 yet unable to separate"反而更准确。建议保留该分析但**改写叙事为"inconclusive, point estimate in the set-point direction"**，去掉"rejecting strict"的过度宣称。

### 1.3 PCA 正交性"显式中立"（L93/S22）—— 属实，且是三条里最致命的一条

- **属实性**：S23 原文"PCA axes are orthogonal by construction ... orthogonality alone is neutral about a single set-point"。完全属实。
- **为什么最致命**：**PCA 轴正交是构造性数学事实**——PCA 产出的主轴必然正交，与任何生物学假说无关。把"PC1（骨量/骨折轴）⊥ PC2（OA 轴）"当作"结构证据"本身就不成立；再补一句"正交对单设定点保持中立"，等于作者自己承认**唯一的结构性证据其实是数学恒真、不能支撑任何方向**。S22 作为"latent structure"图，对 SOS 既不能证成也不能证伪，是**空洞的支撑线**。
- **附加脆弱性**：该 PCA 建在 13×13 LDSC r_g 矩阵上，而 OA 的 h² 仅 0.035、r_g 涉及 OA 的条目估计误差很大 → 轴不稳定，PC2（14.1%，仅由 2 个噪声 OA 变量驱动）尤其可疑。即便撇开"正交是构造事实"，其**数值也不可靠**。
- **结论**：R1 第 3 条是最站得住的；建议**彻底移除"PCA 作为结构证据"的叙事**，改写为"探索性降维显示 BMD 与 OA 落在不同轴（预期之内，因 PCA 轴本就正交），仅为描述性、非机制检验"。

## 2. R1 漏掉的两个更深的致命问题

### 2.1 回顾性预注册使整个 P1–P6/F1–F10 框架成为事后合理化

`docs/118` 第 6 行原文：
> "the genetic analyses reported in the accompanying manuscript were *completed* before this document was written. This preregistration therefore follows a *retrospective* format: the six predictions (P1–P6) are declared as **derived predictions** — a post-hoc organisational scaffold built from the results ..., explicitly *not* prospective forecasts."

这是**结构性致命伤**，R1 若细读预注册会立刻抓住：一个在结果出来后才写的"预注册"，且明确声明 P1–P6 是"derived / post-hoc"，**不可能支撑"假说检验"的声称**。用同一批数据派生预测、再用同一批数据"确认"派生预测，不是假说检验，是循环。这不是改文字能救的——是认识论层面的缺陷。

**对策**：诚实承认 P1–P6/F1–F10 是**事后组织框架**（已在 docs/118 声明），把它从"假说的检验装置"降格为"透明的、事后标注的猜想—证伪登记"，放进 Supplementary，并在主文明确"本研究的贡献是描述性发现，SOS 为事后提出的、可证伪的解释性猜想"。

### 2.2 框架自相矛盾：既是"中心假说"又自承"不支持"

S23 称 SOS 为"the central Systemic Osteogenic Set-point (SOS) hypothesis"，主文用 P1–P6/F1–F10/S11/S21/S23 一整套装置围着它转；但 Discussion（L93）又把它拆成"not supported / neutral / spans zero"，并直说"SOS is therefore best read as the descriptive bone–cartilage paradox repackaged plus one untested single-set-point discriminator"。

审稿人读到的画面是：**你用一整套精密装置去检验一个你自己已经承认"不支持、判别核未检验"的假说。** 这不是假说论文，是穿着假说外衣的描述性论文。这种自相矛盾比任何单条证据都更伤 sellability——它让审稿人怀疑作者自己都不信 SOS。

**对策**：统一叙事——要么（选项①）把 SOS 从"中心假说"改为"主要发现之一是方向性模式，SOS 为可选解释"；要么（选项②）给出真正的先验生成模型并承受其 inconclusive 结论。不能两者兼有。

## 3. 扩展对抗性极限审稿（R1 之外的额外漏洞）

### 3.1 理论循环定义：SOS = 它要解释的模式本身
SOS 定义为"一个设定点升高 BMD、降低骨折、升高 OA"。而 SOS 的"证据"正是 MR 显示 BMD→OA 正、BMD→骨折负。于是"证实 SOS" = "观察到你据以定义 SOS 的模式"。SOS 唯一非同义反复的部分是判别核（同一套变异固定相反符号），而该核恰好"不受支持"。所以 SOS 相对描述性悖论**没有新增任何被支撑的内容**——L93 自己已承认这点。

### 3.2 因果方向未稳健建立 → "设定点导致相反结局"失去前提
正向 MR（BMD→OA 正）是稿件因果主张的支柱，但反向 MR（OA→BMD，P5）功效仅 0.14–0.26，作者自承"null, as predicted"实为"功效不足下的 null"。没有稳健的因果方向，"一个设定点*导致*相反结局"就塌了——你无法在因果方向都未确立时主张一个因果设定点。

### 3.3 F2 体积臂未执行——决定性因果分解缺失
areal BMD 融合 mass + size + geometry；判定"osteogenic（骨形成）"解释的关键是把 mass 与 geometry/size 分解开。真正的体积 BMD（vBMD）MR 这一"decisive arm"作者自承 unexecuted。于是中心因果主张建立在一个成分未知的合成表型上，恰好削弱"骨形成"这一特定解释。

### 3.4 多重性放大不确定
13 表型 × 10 MR 对 × LDSC 矩阵 × 31 工具多阈值 colocalization。9/31 分裂（p=0.0043）与 2/5 随机效应显著（R2-1 已自承 exploratory、非多重性校正）。即便"支持性"信号也是多重性未调整的。

### 3.5 概念新颖性稀薄
骨-软骨悖论文献 30+ 年（`docs/08` 引 [3,4],[49],[50]）。SOS 的新颖声称是"单设定点判别核"，而该核不受支持。所以"新在哪？"的答案是：把 MR/colocalization 三角验证用于悖论 + 一个不工作的判别核。真正的新颖是**多表型遗传架构 + 三角验证（描述性内核）**，而非 SOS。

### 3.6 S22 PCA 建在噪声矩阵上
OA h²=0.035 → 涉及 OA 的 r_g 估计误差大；PC2（14.1%）仅由 2 个噪声 OA 变量驱动，轴不稳定。叠加"正交是构造事实"，S22 既不能证成也不能证伪 SOS，作为"结构证据"名不副实。

## 4. 深度思考：SOS 能否被挽救？

### 4.1 选项②（可定量证伪生成模型）为什么既不可行也不充分
- **不可行**：P1–P6 的先验性已被 docs/118 的回顾性声明永久破坏——它们永远无法成为"a-priori predicted values"。重写一篇"生成模型"也不能抹去预注册是回顾性的事实。
- **不充分**：即便写出规范生成模型（先验指定 S→BMD(+)、S→骨折(−)、S→OA(+)，预测 corr(θ_fx, θ_oa) 显著 <0），数据（31 工具、coloc 功效不足、反向 MR 0.14–0.26）**仍无法定位 ρ**。生成模型只会把"不确定"显式化并给出一个 inconclusive/弱的负向结论，从而把 SOS 降级为"未被支持的猜想"——这恰好又回到选项①。
- **结论**：选项② 是路径错误，它收敛到选项①。

### 4.2 选项①（重定位为描述性多表型遗传架构 + 三角验证）为什么正确且充分
- 稿件的**实证内核已经是这个**：13×13 r_g 矩阵、BMD 遗传升高 OA 风险却降低骨折风险、5 位点方向一致、EUR-only 复制（S35）、LDSC/MR/MVMR/colocalization 三角验证。SOS 外衣是装饰。
- 重定位主要是**重构叙事与章节顺序**，不是新分析，成本可控、诚实、可发表。
- v2.6 已走到 70%（标题描述性、L23 "hypothesis not demonstrated mechanism"、L93 "descriptive paradox repackaged"），只差**不再称 SOS 为"中心假说"、把 P1–P6/F1–F10 降为透明补充登记**。

## 5. 切实解决方案（具体落地步骤）

### 5.1 重定位为描述性研究的 N 步重构
1. **标题**：已是描述性（"...associated with higher knee-OA risk yet lower fracture risk: pleiotropy-aware MR evidence"），去掉任何"set-point"字样即可（若含）。
2. **摘要**：以实证发现开篇（13 表型遗传架构；BMD 遗传升高 OA 风险却降低骨折风险；5 位点方向一致 + EUR-only 复制 + 三角验证）。SOS 仅在末句作为"解释性猜想"出现："compatible with, but not demonstrating, a shared osteogenic set-point; offered as a falsifiable hypothesis, not a demonstrated mechanism."
3. **主文 §4/讨论重构**：从"中心假说 SOS + P1–P6/F1–F10"改为"实证架构（发现）→ 解释（SOS 作为若干机制假说之一，明确可证伪且当前判别核不受支持）→ 局限"。
4. **降级 S21/S23/P1–P6/F1–F10**：移入 Supplementary "Hypotheses and falsification register"，**透明标注为事后**（`docs/118` 回顾性预注册），不再是主文脊柱。保留它们（展示严谨与诚实），但不再组织主文。

### 5.2 SOS 的正确定位（透明标注的可证伪猜想，而非中心假说）
主文一句定调："SOS 是从本数据事后提出的解释性假说；其判别预测（同一套变异固定相反符号）当前数据不支持；我们将其作为明确标注的可证伪猜想保留，并指明可支持或推翻它的检验（F2 体积臂、F10 跨祖先）。"

### 5.3 抢救真正 strengths（当前被埋没）
- **F6 跨位点同质性（τ²=0, Q_exact p=0.14）**：方法扎实（`code/124` 处理共享工具协方差、Cholesky 验证），是"BMD→OA 效应系统一致而非部位特异"的**真实、功效充足**证据。应在主文显著呈现，而非只在 L93 一笔带过。
- **EUR-only knee-OA MR（S35）**：5/5 正向、OR/SD 1.06–1.12，真实 within-ancestry 复制， genuine strength。
- **9/31 vs 0/31 coloc 对比（p=0.0043）**：方向性提示（骨折端骨侧信号），但须保持 exploratory / 多重性未调整。

### 5.4 修正 ρ̂ 与 S22 叙事
- ρ̂=−0.13：改写为"bivariate coupling analysis is power-limited and cannot locate coupling strength; the point estimate (−0.13) is in the set-point direction but the CI spans zero, so the analysis is inconclusive rather than refuting the set-point." 去掉"rejecting strict ρ=−1"的过度宣称（M1 的 ρ=−1 本身是最极端稻草人）。
- S22：改写为"exploratory dimensionality reduction; PCA axes are orthogonal by construction, so this is descriptive, not a test of mechanism; OA axis is driven by low-h² OA variables and is unstable."

### 5.5 若坚持 SOS：生成模型最小规范 + 为何仍收敛到①
最小规范：先验指定 latent S 的 polygenic 架构与 S→BMD(+)/S→骨折(−)/S→OA(+) 的符号结构；**先验**定量预测 corr(θ_fx, θ_oa) 显著 <0；附 a-priori 功效计算（31 工具在观测 SE 下检测 ρ=−0.5 的功效约 X%）。但：回顾性预注册使"先验"不可信；且即便规范，数据仍无法定位 ρ，结论必为 inconclusive/弱负 → SOS 降级为猜想 → 落到选项①。故不推荐。
