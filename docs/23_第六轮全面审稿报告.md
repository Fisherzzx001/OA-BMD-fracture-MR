## 【Reviewer 1 理论贡献】—— 三条结论

**P0-1 已闭合（确认）：** 原"标题=确定性负向断言、正文=underpowered 非结果"的自相矛盾已消除。标题、§4.3 小标题、§4.6 结论、摘要结论现已统一为 hedged 表述（"no well-powered evidence…", "remains limited"）。✅

**残留漏洞 1（致命）：机制层未与"骨尺寸/面积"这一最强竞争解释对话。**
§4.2 的机制读法是"全身 BMD↑ → 共享效应基因（WNT16/SOX6/GDF5）→ 软骨下骨硬化/骨赘 → OA"。但 OA–BMD 遗传相关（以及 BMD→OA 的 MR）最经典的**替代解释**是：更大的骨骼 = 更高的面积 BMD（DXA 测得）+ 更易患 OA 的关节形态。换言之，OA 与 BMD 的正相关可能部分由**骨骼尺寸/几何**这一第三变量驱动，而 MR（BMD→OA）若 BMD 代理了骨尺寸、骨尺寸又直接致 OA，则存在水平多效性混杂。全文未提"bone size / skeletal size / femoral geometry"一字。删除这篇，领域少的是"10 站点分辨率"，不是"骨尺寸机制对话"——理论贡献因此停留在"现象分辨"而非"机制分辨"。**建议：** §4.2 补一段，明确将"骨尺寸/面积"列为 OA–BMD 正相关的竞争解释，并说明 MR 与 LDSC 能否/如何与之区分（至少诚实承认这是未分离的机制层不确定性）。

**残留漏洞 2（已改善，仍弱）：** 第五轮指出的 hip–knee"反转"伪对比，本轮 §4.2 已改写为"hip-versus-knee contrast rather than a contradiction"，并加了负重/非负重 cautious note——改善明确，记功。但 §4.3 仍声称"femoral-neck (+0.017) 未大于 arms (+0.022) 支持 systemic 机制"，随即自驳"0.005 gap is within sampling error"。这种"先主张后撤销"在理论层是弱支撑，建议要么正式做 weight-bearing vs non-weight-bearing 检验，要么把该句降级为纯假设。
