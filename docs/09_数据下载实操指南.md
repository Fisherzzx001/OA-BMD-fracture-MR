## 一、UKB 观察性字段下载

### 1.1 字段定位（先去 Showcase 核对，字段编号可能随版本微调）

| 字段 ID | 名称 | 类别 | 结构 | 参与者数 | 备注 |
|---|---|---|---|---|---|
| **20002** | Non-cancer illness code, self-reported | Self-reported | Categorical (multiple, array) | ~502k | 自检非肿瘤病史，3 位码（含 OA=1462） |
| **41270** | Diagnoses – ICD10（住院总结诊断） | Hospital inpatient → Summary Diagnoses | Categorical (multiple, array 0–258) | 448,651 | 住院 ICD-10 全部 distinct 码 |
| **41280** | Date of first in-patient diagnosis – ICD10 | 同上（日期配套） | Date array | — | 与 41270 **按 array 顺序对齐** |
| **20003** | Treatment/medication code | Self-reported | Categorical (multiple, array) | ~502k | 自检用药/治疗码，辅助确认 |

配套字段（匹配与协变量用，一并申请）：
- `31` 性别 / `34`+`52` 出生年月 / `21003` 基线年龄(instance 0) / `21000` 族群
- `53` 入组评估日期 / `40000` 死亡日期 / `191` 失访日期
- `20001`（自检肿瘤史）、`20004`（自检内科操作）—— 可选

字段页面直达（把 id 换成上面数字）：
`https://biobank.ndph.ox.ac.uk/ukb/field.cgi?id=20002`

> 这些字段属于 **Cost Tier 0（免费/低费率）** 层，单列申请即可，无需付费影像/组学。

### 1.2 申请与权限（必须先过这一关）

1. **注册 AMS**：https://ams.ukbiobank.ac.uk/ams/signup
   - 用学校/机构邮箱；填真实姓名、单位、课题摘要。
2. **找机构担保**：UKB 要求申请由**获批机构**（你所在大学/医院，需有 OUR 编号）提交。
   - 你之前记的「找 1 位英国合作者/机构担保」正是这一步 —— 没有英国机构 OUR 编号无法提交主申请。
   - 备选：若你所在中国院校已注册为 UKB 获批机构，可由本校 PI 提交。
3. **提交 Data Access Request**：在 AMS 里建项目 → 勾选上述字段 → 说明研究目的（共病网络、OA 双库对比）→ 送伦理/审批。
4. **费用**：基础表型（含上述字段）通常免收数据费；学生优惠费率（你备忘录里记的 £500 学生档）仅适用于**特定影像/增强数据**或早年政策，**2026 年以 UKB「Access Fee」页面为准，提交前务必向 UKB 邮箱确认当前是否仍有效**。
   - 审批周期：机构担保到位后一般数周。

### 1.3 下载方式 A：本地 bulk download（ukbconv）—— 推荐（便于 Python 管线）

UKB 把「主数据集」以加密包交付，本地解密后转 CSV 子集。

1. **取工具**：https://biobank.ctsu.ox.ac.uk/crystal/download.cgi
   - `ukbunpack`（解密）、`ukbconv`（转换/子集）、`ukbfetch`（拉 bulk 文件，影像用）。
   - Windows 版在 `windows_tools/`，Linux/Mac 在 `linux_tools/`。
2. **下载主数据集**：AMS 项目批准后，Showcase → 你的项目 → Download，拿到
   - `ukbXXXXXX.enc`（加密主数据，XXXXXX=run id）
   - `kXXXXXXrYYYYYY.key`（密钥文件，邮件另发）
3. **解密**：
   ```bash
   ukbunpack ukbXXXXXX.enc kXXXXXXrYYYYYY.key
   # 产出 ukbXXXXXX.enc_ukb（解密后的主数据集）
   ```
4. **建字段清单** `field_list.txt`（每行一个字段号）：
   ```
   31
   34
   52
   21003
   21000
   53
   40000
   191
   20002
   41270
   41280
   20003
   ```
5. **转 CSV 子集**（含该字段所有 instance/array 列）：
   ```bash
   ukbconv ukbXXXXXX.enc_ukb csv -ifield_list.txt
   # 产出 ukbXXXXXX.csv；列头格式 F-I.A（字段-实例.数组）
   ```
   > 注意：41270 会展开成 259 个数组列（41270-0.0 … 41270-0.258），
   > 20002/20003 也会展开成数十列。文件较大但可管理（数百万单元格量级）。

### 1.4 下载方式 B：UKB Research Analysis Platform（RAP，DNAnexus 云端）

适合不想下载大文件、直接在云端用 Python/R 跑分析的场景。
- 入口：https://ukbiobank.dnanexus.com/ （或 NIH 镜像 https://ukb.linkinghub.nihr.ac.uk/）
- 在 RAP 里用 **table-exporter**（实体 = `participant`）选字段，或直接用 **dx** 命令行。
- 41270 在 RAP 中是一列 **JSON 数组**（`p41270`）；对应日期在 `p41280_a0, p41280_a1, …`，
  **第 N 个码 ↔ p41280_aN**。
- 若要**逐次住院记录**（非总结码），切换实体到 `hesin_diag` / `hesin`（表级明细），
  用 Resource 138483（HES 数据处理说明）对齐。
- 云端分析省下载，但 1:1 匹配 + 网络计算建议导出子集到本地更稳。

### 1.5 数据结构与提取（最关键，直接决定网络能否建）

- **20002（自检非肿瘤病史）**：每个参与者一行，展开成数十个数组列，每格是一个 3 位整数码。
  码→病名映射看字段页「Values」标签（coding 6 / 19）。OA 自检码 = **1462**。
  建病旗：`any(20002 各列 == 1462)` → OA 自检阳性。
- **41270 / 41280（住院 ICD-10）**：
  - 本地：41270 列是 `A00|B10|C20…` 用 **`|` 管道符**拼接的单列；41280 是其对应的首次诊断日期数组。
    拆分 41270 的 `|` 后，**第 k 段 ↔ 41280 的第 k 个数组**（UKB 官方确认此对齐）。
  - RAP：41270 是 JSON 数组，直接 `json.loads` 后与 `p41280_a*` 按序对齐。
  - 建病旗：把 ICD-10 码按「前缀匹配」映射到 CNS 病（如 `M17`→膝 OA，`M16`→髋 OA，`I10`→高血压，`E11`→2 型糖尿病）。
- **20003（自检用药）**：数组列，码→药名映射见字段页 Values；用于二级确认（如 OA 患者是否用 NSAID/关节置换相关操作码）。

> ⚠️ 41270 含「umbrella code」（如 I48 房颤、M75 肩病），UKB 官方说明这些既可能是
> 具体亚型的汇总也可能是真实未细分诊断 —— 建病旗时按前缀匹配即可，不必刻意剔除。

### 1.6 落地到 CNS（共同节点集）

B 档锁定 **CNS = 16 病**（若 CHARLS 无 osteoporosis 字段则降为 16 去 OA，否则 17）。
对 UKB 侧，把每个 CNS 病写成一条「码→标志」规则：
- 自检来源（20002）+ 住院来源（41270 ICD-10 前缀）**取并集**（任一来向阳性即计为该病阳性）。
- 灰度处理：UKB 双轨表型 —— T1 `any OA`（20002==1462 或 41270 含 M15/M16/M17/M18/M19），
  T2 `症状性下肢负重关节 OA`（用 41270 的 M16/M17 + 自检症状组合，次要分析用）。

## 二、CHARLS 下载

### 2.1 注册与申请

1. **官网注册**：https://charls.pku.edu.cn → 右上「数据用户注册」
   （或直接 https://charls.charlsdata.com/users/sign_up/agreement/zh-cn.html）
   - 强密码（≥10 位含大小写）；**用学校邮箱**加速审核。
   - 如实填真实姓名 + 单位（学术诚信核查用）。
2. **签数据使用协议**：承诺仅学术用途、不识别个体、发表时署名
   「感谢北京大学国家发展研究院和北京大学中国社会科学调查中心提供 CHARLS 数据」。
3. **激活邮箱**：去垃圾邮件找 `charls_info@pku.edu.cn` 的激活邮件，点确认。
4. **申请数据**：登录后对每个波次（Wave）公开发布数据点「申请数据」，
   **约 3 个工作日内批准**。CHARLS 对学术用户**完全免费**。

### 2.2 下载

- 批准后数据列表出现「下载」→ 拿到 **WinRAR 压缩包**（内部为 **Stata `.dta`**）。
- 解压用 WinRAR；打开用 Stata，或转 CSV（Python `pandas.read_stata` / `pyreadstat`）。
- 建议下载的波次（B 档需 ≥2 波做库内 1:1 匹配 + 跨库对比）：
  - **2011 基线（Wave 1）**、**2013（Wave 2）**、**2015（Wave 3，含 Biomarker）**、**2018（Wave 4）**。
  - 若要做纵向，可加 2020（Wave 5）/ 2023（Wave 6，若已发布）。
- 每轮务必同时下 **用户手册 + 问卷（codebook）**，变量含义以 codebook 为准。
- Harmonized CHARLS（跨波合并版）：https://charls.charlsdata.com/pages/Data/harmonized_charls/zh-cn.html
  （适合快速纵向，但自建网络建议用原始分波更可控）。

### 2.3 数据结构（慢性病模块 → CNS 病旗）

- CHARLS 慢性病为**自检「是否被医生诊断过」二元变量**（health status & functioning 模块）。
- 变量名随波次微调，**务必查当波 codebook 的「健康状况」章节**定位（不要硬编码变量名）。
- 通用模式：每个病一个 `是否曾被医生诊断` 的问题 → 二值（1=是 / 5=否 / 否则缺失）。
- 对 CHARLS 侧同样建 CNS 16 病标志：高血压、糖尿病、心脏病、卒中、慢阻肺、癌症、
  肾病、肝病、关节炎/骨关节病、抑郁症等（CHARLS 覆盖的大多能与 UKB 的 CNS 对应）。
- 匹配键：年龄（调查年−出生年）、性别、调查波次（CHARLS 的 wave）、地区（省份/城乡）。

### 2.4 引用（发表必带）

- 基线：Zhao et al., 2014 (CHARLS baseline) ；各波次对应 CHARLS 技术报告。
- 数据库致谢语句见 2.1 协议。

## 三、打通到 B 档管线（落库步骤）

1. UKB 侧：`ukbconv` 导出子集 CSV → `01_build_cohort.py` 读入 → 建 eid + CNS 病旗 + 匹配键。
2. CHARLS 侧：`.dta` → `pandas.read_stata` → 建个体 ID + CNS 病旗 + 匹配键。
3. 两库各自 1:1 匹配（OA 病例 : 非 OA 对照，年龄±1 + 性别 + 波次/中心）。
4. 跨库 O/E 网络（H2/H4 用等密度 K = min(CHARLS-OA 边数, UKB-OA 边数)），
   置换检验 + FDR，模块 O/E 均值量化聚集强度。
5. 字段编号复核：UKB 字段号稳定；CHARLS 变量名**每波须复核**（你备忘录里标 ⚠️ 项）。
