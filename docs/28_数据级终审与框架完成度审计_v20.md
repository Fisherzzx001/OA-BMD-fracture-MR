## 1. 本轮做法与以往审计的根本差别

此前审计的交付物是"我检查过了 / 236 项全过"。本轮交付物改为**可追溯的证据链**：
每条声称 → 对应**脚本第几行** → 用什么**独立手段**验证 → 判定。

新增门禁 `audit_v20_trustbutverify.py`（570 行），与 v19 的关键差别：

| | audit_v19_fresh.py | audit_v20_trustbutverify.py |
|---|---|---|
| 是否读稿件文本 | **否**（grep 全文件无 `08_`/`.md` 引用） | **是**（解析 Table 1–4、正文段落） |
| 期望值来源 | **硬编码**（:133-145 字面量） | 从 harmonised 逐 SNP 重算 |
| 结论含义 | "重算值 == 硬编码常量" | "重算值 == 稿件文本" |
| 改错数字能否被发现 | **不能** | 能 |

> 这是本轮最重要的元发现：一个从不读稿件的门禁，无论跑出多少"PASS"，都不是稿件正确性的证据。

## 3. Part A2 · 可进一步加强与完善的工作（按优先级）

**P1（对"因果"主张的说服力影响最大，建议投稿前或返修时补）**

1. **共定位分析（coloc / SuSiE）** — 目前 WNT16、SOX6、GDF5 被称作"候选共享效应器"，但**从未检验共享因果变异**。这是本文从"遗传相关 + MR"升级到"机制位点"的关键缺环，也是审稿人最可能追问的点。
2. **多变量 MR（MVMR）拆分骨尺寸 vs 骨量** — §4.2 已自认"需 volumetric BMD 或髋几何 GWAS 及条件/多变量 MR"。可用身高 GWAS 作代理做 **BMD + 身高** 的 MVMR，至少给出尺寸路径的量级上界，把目前的纯文字推测变成有数字的敏感性分析。
3. **Steiger 方向性检验** — 强化"BMD→OA 而非 OA→BMD"的方向主张，成本低。

**P2（提升可信度与广度）**

4. **官方 LDSC 交叉验证** — 用官方工具在同一批 munged 文件上跑一次，与自研实现比对 r_g 到 3 位小数。可一举消解"自研实现是否可靠"的审稿疑虑。
5. **独立队列/表型复制** — 现为单一欧洲 ancestry、单一膝 OA 定义。可用髋 OA 或手 OA GWAS 做方向性复制（哪怕只报告一致性符号）。
6. **性别分层 MR** — OA 性别差异显著；`code/output/sensitivity/S8_sex_stratified.csv` 目前只服务 CHARLS 网络，MR 尚无性别分层。

**P3（锦上添花 / 卫生问题）**

7. 仪器 **PheWAS** 评估多效性广度。
8. §2.8 明确 ρ_GE 取的是 `rho_GE_zcorr` 列（本轮核验：该列 −0.791…+0.460 与正文"−0.79 至 +0.46"精确吻合；另一列 `rho_beta` 为 −0.806…+0.437，正文未指明列）。
9. 清理派生文件命名与标签（见 F3、以及既往记录的 `rg_h2.csv` 占位 N 问题）。
