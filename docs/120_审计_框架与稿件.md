## 3. 门禁错误清单（含稿件↔门禁↔构建不一致）

### G1（高）· 稿件性别局限声明虚假且与门禁矛盾
- 稿件 L49：「All four … none is stratified by sex, so every estimate here is sex-averaged and **effect modification by sex cannot be tested** — a material limitation」
- 稿件 L99：「All estimates are sex-averaged and **effect modification by sex is untested** (deposited statistics are not sex-stratified).」
- 门禁 docs118 L58：**F8 已于 2026-10-18 执行**，用 Boer 2021 性别分层 GWAS 重跑 BMD→OA MR，两性均正（KneeOA F+0.320/M+0.451；AllOA F+0.344/M+0.233），方向不反转。
- **判定**：稿件比门禁**陈旧且错误**。错因：把"主分析用性别合并 GWAS"偷换为"性别效应不可检验"；F8 证明可用外部性别分层 GWAS 检验，且已检验。属应当删除的错误自贬陈述。

### G2（高）· P2 排序 p 值 0.18 错误；门禁内部不自洽
- 稿件 L95 与门禁 docs118 L41(P2 行) 均写 `p = 0.18`。
- 门禁 docs118 L59(F9 行) 写 `p = 0.228`。
- 独立验证（C3）：真值 **0.2278**（diff=0.0051, se=0.0068, z=0.751, 单侧 p=0.2264≈0.228）。要得到 0.18 需 se≈0.0056（即忽略 arms 自身方差的错误 SE）。
- **判定**：稿件与门禁-P2 行都错；门禁-F9 行正确 → **docs/118 内部 P2 与 F9 不自洽**（同一量 T3a 排序 p 出现两个值）。`code/160` L72 注释、`tier1_site_gradient_summary.json` `conclusion` 字段也误称"consistent with manuscript P=0.18"，须一并改。

### G3（高）· 错尺度进程产物 `mr_results.csv` 仍挂构建链
- `code/output/genetics/mr_results.csv`：BMD_total→OA_knee ivw=**0.0819**（稿件 0.023 的 ~3.5×），OR=1.085；阳性对照 OR=exp(1.195)=**3.30**（与 GEFOS 1.55 矛盾）。
- 该文件被以下脚本/产物直接读取（grep 证实）：
  - `code/14_figure3_mr_forest.py` L21（Figure 3 森林图，直接 `r.ivw` 绘图）

  - `build_package_v16.py` L49（`"mr_results.csv"` 进 Table3 源）
  - `build/pkg_stage/Table_Source_Data/mr_results.csv` L4（β=0.0819）
  - `code/output/genetics/mr_presso_results.csv` L4（同错尺度）
- **正确源已存在**：`code/output/genetics/mr_results_corrected.csv` L4 → BMD_total→OA_knee ivw=**0.02312**, se=0.00369, p=1.09e-10（audit_v20 亦确认其加权中位数 −0.392 与独立重算 −0.364 吻合）。
- **判定**：稿件*文本*正确，但**若重跑** `code/14_figure3` 或 `build_package_v16` 会用错尺度产物，使 Figure 3 / Table 3 源与文本矛盾（图显 β≈0.082 vs 文 β=0.023）。属"进程遗留、比稿件更错"的典型陷阱，必须改指 corrected 源或从 harmonised 重算。
