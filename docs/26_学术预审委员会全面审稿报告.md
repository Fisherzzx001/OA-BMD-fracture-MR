## 【Editor】主编预筛

**评分：7.5 / 10。** 标题精准传达核心（BMD 与 OA 共享遗传架构，但 OA→骨折因果证据有限）；摘要五要素齐全（Objective/Methods/Results/Conclusion 俱备）；引言前三段能抓住注意力（1972 Foss & Byers 开篇，临床张力清楚）。语言体例达标，STROBE-MR 合规声明在 §2.7。

**放行条件（为何不是秒拒）：** 方法诚实、阳性对照到位、局限披露充分——这是合格 MR 论文的底子。

**主编最担心的两件事（决定能否送审）：**
1. **标题与结论的因果强度 vs 证据强度错位。** 结论句「higher BMD … raises knee OA risk」听起来是与「protects against fracture (OR 1.40)」对等的因果发现；但前者是每 1-SD 斜率 +0.017~+0.028、且**不是比值比**（§3.5 明确不取指数），后者是真实 OR。两句并列暗示同等力度，实则证据底座差一个量级。主编会在 30 秒内抓到这个不对称。
2. **效应量过小 + 高异质性。** β=+0.017 per SD 在任一临床期刊看来都接近噪声；若随机效应下仅 2/5 显著（§3.4），「raises knee OA risk」作为主结论显得勉强。

**契合度：** *Bone* / *Osteoporosis International* 是天然归宿（BMD 中心 + BMD–骨折阳性对照）；*OAC* 进取但有风险（审稿人会逼问机制与临床意义）。建议按 §5.3 先投 *Bone*。

## 【Reviewer 1】理论贡献质询师

**视角：顶刊理论审稿人，厌恶现象描述。**

**3 个最致命的理论漏洞：**

1. **「去掉这篇论文，领域少什么？」答不稳。** 核心发现（BMD→OA 正向因果、BMD→骨折保护）本质是 Zhou 2025（髋 OA）与经典 BMD–骨折关系的**扩展/复制**；十个位点的设计是**方法学增量**，不是理论突破。「r_g 双向、因果单向」的提法增量有限。真正的理论增量只有两点——**骨骼尺寸混淆洞察**（§4.2）与**首次 OA→骨折方向直接检验**——但二者都被处理成次要内容。
2. **「共享效应因子」假说未被检验，却占据理论C位。** §4.2 抛出 WNT16/SOX6/GDF5 作为候选共享效应器，随即自己承认「direct evidence … lacking, requires joint-specific functional validation」。这是假说，不是贡献。文章未提供任何机制检验，却用它来解释「 paradox 已解决」——理论建构停在猜想层。
3. **骨骼尺寸混淆反而消解了主因果主张。** §4.2 自己指出：areal BMD 受骨骼尺寸混淆，BMD→OA 效应可能反映「骨尺寸」而非「骨量」。那么标题「higher BMD raises knee OA risk」中的 BMD 若含尺寸成分，因果主张就被自身局限削弱。文章诚实披露，但结论句未同步降级。

**深化理论建构的方向：**
- 把贡献重新框定为**「首个将 OA–BMD–骨折三角联合分析、区分遗传共享与因果方向、并量化骨骼尺寸混淆的研究」**，而非「解决 paradox」。
- 将尺寸混淆从「limitation」提升为**核心理论命题**：提出可检验假设「BMD→OA 效应 = 骨量通路 + 骨尺寸通路」，并指出用体积 BMD/股骨几何 MR 可分离——这比罗列 WNT16 更有理论重量。
- 对 OA→骨折的 null，明确其理论含义：不是「OA 不导致骨折」，而是「遗传层面无强因果信号」，为环境/功能通路（跌倒、少动、肌少症）留出版图。

## 【Reviewer 3】文献对话审查专家

**视角：精通领域脉络，专抓伪创新与稻草人。**

**文献对话评估：**

- **Research Gap 推导自洽**（§1 三问：位点特异性、两种 OA 定义、OA–BMD–骨折三角）——真实存在，非堆砌。✓
- **「首个直接检验 OA→骨折方向」（§4.3）**——经查证大概率成立，非伪创新。✓
- **缺失的关键对话：**
  1. **「OA 中的骨」机制文献几乎未引。** §4.2 讨论软骨下骨硬化、骨赘、WNT/SOX6/GDF5，却未引「bone in OA / arthritic bone」经典与近期综述（如 Reid 等关于 OA 与骨量、及 GO Consortium 2025 自身对 OA 位点的骨相关注释）。机制段单薄，像孤立猜想。
  2. **BMD→OA 的 MR 文献不止 Zhou 2025。** 应系统回顾既往 OA 风险因子 MR（含 Alhassan 2024 综述 Ref 16 已引，但应点名其中与骨代谢相关的具体研究），以定位本文在「骨–OA」因果谱系中的确切位置。
  3. **阳性对照的文献锚定充分**（GEFOS 2018 引了），但 OR 1.40 vs 1.55 的 8–10% 差距未讨论**为何**偏小（队列/骨折定义/BMD 测量位点差异之外的可能原因，如 UKB 重叠导致的本文低估）。
- **「伪创新」嫌疑（需主动化解）：** 称十个位点「site specificity can be assessed」是卖点，但结果上五个 BMD 位点效应高度一致（+0.017~+0.028），**并未真正揭示位点特异性**——反而支持「系统性」机制。卖点与实际发现略错位，易被指打稻草人（声称测特异性，实则证系统性）。
- **OA_selfrep Z 符号校正的循环论证风险（§3.2）：** 「block 符号依赖该校正，校正由 GDF5/FTO 方向与 +0.84 OA–OA 一致性佐证」——但 +0.84 本身正是校正后的产物。佐证部分循环。需引入**独立于本研究**的验证（如与已发表 OA_selfrep 效应方向直接比对），否则整块 OA×BMD 阳性信号与 +0.84 相关性站在一个全局符号翻转上，脆弱。
- **时效性/规范性：** Ref 16/17/18 有 DOI+PMID 但缺卷/期/页（*Arthritis Care Res* 2024、*Ann Med* 2025、*Bone* 1995），目标期刊多要求完整卷期页，投稿前补填。

## 【Reviewer 2】方法论审查员

**视角：方法洁癖，逐项对照 MR 透明度（STROBE-MR，文章已自陈合规 §2.7）。**

**亮点：** 共用 SNP 集（690,150）使 r_g 矩阵可比；严格 clump + 1-Mb 敏感性；阳性对照内嵌；MRlap 重叠校正；功效分析（§3.8）——透明度高于多数同档 MR 文。

**必改（Must-fix）：**

1. **【最致命】BMD 暴露 N 重建假设撑起全部正向 MR 量级。** 源 BMD GWAS 写死占位 N=400,000，正向 MR β 整体 ÷3.5426 才得「真值」。方向/p 值确实 N 不变（✓），但 **OR 1.40 完全是假设 N=31,873 的产物**。一旦每位点真 N 浮动，所有正向效应量级随之变。文章 §3.7 已做敏感性（±2.3%），但**摘要把 OR 1.40 当作发现陈述**——主编/方法审稿人会要求摘要明示「量级依赖重建 N」。建议在摘要 Results 加半句「on the N-reconstructed scale」。
2. **样本重叠未完全闭合，且 BMD→OA 效应量级落在重叠偏倚区间内。** 每对都共享 UKB；Burgess 上界（≤2.6% for OA、≤12% for fracture）是「假设 100% 重叠」的夸大上界（文章已认）。但 BMD→OA 的 +0.017 量级与 r_g(+0.12~+0.25) 同阶，**重叠偏倚本就可能把 IVW 推向 r_g 方向**；MRlap 把效应「推离零」被文章读作因果确证，但同等可能只是 MR 估计向 r_g 回归（即重叠混淆）。§2.8 未把这个歧义说死。必须明文：重叠不能完全排除为 BMD→OA 量级的驱动者。
3. **「raises knee OA risk」的临床可解释性缺口。** β=+0.017 per SD 是源 GWAS 线性模型尺度、**非 OR**（§3.5）。读者/临床编辑无法把 +0.017 翻译成「风险增加 X%」。建议补一个近似可解释尺度（如按粗略患病率做 per-SD OR 近似，或至少给「相当于 Z 分数每 +1 SD 的线性效应」的直白话），否则因果风险措辞过度。
4. **固定效应 vs 随机效应的逻辑错位（见 Reviewer 4）。** I²=68–86% 下，文章「不以随机效应为因果依据，五对固定效应均显著」——固定效应对高异质性更不保守，以此立论弱。方法上应改以**多效性稳健估计量（MR-Egger / 加权中位数 / MR-PRESSO）为因果主证据**，而非固定效应 IVW。

**建议改（Should-fix）：**

5. **MRlap 的 r_g 与主体 LDSC 的逐位点差应明示。** §2.8 称 MRlap r_g「agreed with primary LDSC」，但 §3.2 列股骨颈×骨折主 r_g=−0.58，MRlap 给 −0.51（差 12%，归因 HapMap3 面板）。应在正文点明这是面板差异而非矛盾，避免被指「选择性报告一致」。
6. **数据可用性占位符。** GitHub URL `https://github.com/<owner>/...` 与 Zenodo DOI `XXXXXXX` 未填（§Data availability）。投稿前必须补全，否则 reproducibility 声明空转。
7. **femoral-neck→骨折 Egger 截距显著（p=0.018）**——该对 IVW 可能膨胀；文章已给 MR-Egger −0.343 / wmed −0.365 为稳健估计，处理得当。建议对该对**以 Egger/wmed 为报告主值**，IVW 降为敏感性。
8. 弱工具下多效性稳健法功效有限（K=16–31），已诚实披露；无需改，但讨论段可再强调「BMD→OA 因果结论更多依赖方向一致性与阳性对照，而非单点估计精度」。

## 【Reviewer 4】逻辑链条审查师

**视角：只审论证结构，不审领域。**

**逻辑链条诊断（断裂点 / 弱支撑 / 跳跃）：**

1. **【断裂】结论句的对称假象。** Abstract/Conclusion「protects against fracture (OR 1.40) **but raises** knee OA risk (β +0.017)」把真实 OR 与非 OR 微斜率并列，暗示等同力度；实际证据底座差一个量级。结论句自身未携带该不对称（虽 §3.8/§4 讨论过）——** headline 与正文逻辑脱节**。
2. **【断裂·最关键】高异质性下的因果立论逻辑自相矛盾。** §3.4：「Under random-effects IVW only two of five remained significant … we therefore do **not** rest the causal claim on the random-effects model, and note that all five remain significant under **fixed-effects** IVW.」 逻辑链：高 I²(68–86%) → 应用随机效应 → 仅 2/5 显著 → 于是**退回固定效应**立论。这是倒因为果：固定效应在 I²=86% 时更不保守，用它撑因果主张最弱。正确逻辑应是「以多效性稳健估计量为准，固定效应仅作敏感性」。当前文本在逻辑上自我削弱。
3. **【过度推论】「unidirectional in causation（因果单向）」。** 该论断依赖 OA→BMD 的 null，但文章自己界定该 null 是「absence of evidence」而非「evidence of absence」（§3.5/§3.8）。结论句却用未缓冲的「unidirectional in causation」——把欠效能 null 升格为方向性结论。§4.6 有「as far as the well-powered estimates show」缓冲，但 headline 句未缓冲，构成过度推论。
4. **【循环】OA_selfrep 符号校正佐证循环**（见 Reviewer 3）：用校正后的 +0.84 一致性去证明校正本身，循环论证；逻辑上整块 OA×BMD 阳性信号悬于一个全局符号翻转。
5. **【歧义】MRlap「推离零」的解读。** §2.8 把 MRlap 强化读作因果确证，但重叠偏倚同样会把 IVW 推向 r_g（非 null）；BMD→OA 的 r_g 本就为正，故「推离零」可能是校正重叠、也可能是 MR 向 r_g 回归。文章未排除后者，逻辑上「强化=因果」不成立。
6. **弱支撑点：** §4.3「系统性机制」论断基于股骨颈(+0.017) vs 上肢(+0.022) 仅差 0.005「在抽样误差内」——文章自己承认，逻辑上应标为「提示性」而非推断，已处理得当，但小标题级可再降调。

**衔接：** 章节间过渡自然，无大跳跃；§2→§3→§4 递进清晰。主要问题集中在「结论强度 > 证据强度」的系统性偏移。

## 综合评分与修改优先级

**总分：7.5 / 10**（方法诚实、透明度高、阳性对照与尺寸混淆洞察是真实亮点；主因果主张的证据底座与表述强度不匹配，是主要扣分项）。

**修改优先级排序：**
- **P0-1（逻辑+理论）**：重框 BMD→OA 因果主张，匹配其证据底座——以多效性稳健估计量为因果主证据、固定效应降敏感性；关闭「高异质性→退回固定效应」的逻辑错位；结论句加缓冲，不写未缓冲的「unidirectional in causation / raises risk」对等 OR。
- **P0-2（方法）**：摘要与结果明示正向 MR 量级依赖重建 N=31,873；补 N 重建敏感性表；数据可用性占位符（GitHub/Zenodo）补全。
- **P0-3（方法+理论）**：明文界定样本重叠残差——BMD→OA 量级落在重叠偏倚区间，MRlap 强化不等于因果确证（可能是向 r_g 回归）；给出重叠无法完全排除为驱动者的直白陈述。
- **P1**：机制段补「bone in OA」文献；把尺寸混淆从 limitation 提升为核心可检验命题；MRlap r_g 与主 LDSC 逐位点差明示为面板效应。
- **P2**：补 per-SD 近似可解释尺度（让 +0.017 可读）；Ref 16/17/18 补卷期页；股骨颈→骨折对该对以 Egger/wmed 为报告主值。

**最该先改的三个问题（Top 3）：**
1. 高异质性下以固定效应 IVW 立因果主张的逻辑错位 + 结论过度推论（P0-1）。
2. 正向 MR 量级（含 OR 1.40）完全依赖重建 N 假设，摘要未明示（P0-2）。
3. 样本重叠未闭合、MRlap「强化」的歧义解读未排除（P0-3）。

**公正亮点（必须保留）：** 阳性对照内嵌验证等位取向与流程正确性；共用 SNP 集使 r_g 矩阵可比；功率分析诚实区分「证明无」与「无证据」；骨骼尺寸混淆的洞察是本文最被低估的理论贡献，应前置而非埋没。
