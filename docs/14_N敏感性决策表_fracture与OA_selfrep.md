## 0. 为什么 N 必须由**外部元数据**决定（不能从数据反推）

LDSC 的识别关系是：

$$E[\chi^2_j] = 1 + \frac{N h^2}{M}\,\ell_j + \frac{N a}{M}$$

回归斜率只给出乘积 **N·h²**，因此 **h² 与 N 不可同时识别**：h² ∝ 1/N。
这意味着——**改变 N 只是在同一条曲线上滑动**，拟合优度不变、截距不变。所以：

- ✅ **N 必须由来源方报告的元数据确定**（OpenGWAS/GEFOS/原文）。
- ✅ **r_g 与 MR 的方向、显著性不受 N 影响**（r_g = gencov/√(h₁h₂)，N 在分子分母中约掉；
  已实证：N 变动 6.7 倍，r_g 三位小数不变）。
- ⚠️ **只有 h² 绝对值与 liability 转换会随 N 改变** → 这正是本表要锁的。

## 4. 已解决：BMD→骨折 MR 量级与 GEFOS 基准吻合（2026-09-16）

GEFOS 2018 的 MR 基准：**股骨颈 BMD 每降低 1 SD → 骨折 OR = 1.55（95% CI 1.48–1.63，P=1.5×10⁻⁶⁸）**。

原先量级对不上，根因已查明并修正：**BMD munge 文件的 N 是占位值 400,000，真实 N=31,873**。
因为 β_重建 = β_SD·√(N_真/N_用) = β_SD × 0.282，BMD 的 β 被低估 3.54 倍 → 以 BMD 为暴露的 MR β 被高估 3.54 倍。
（β 与 SE 同因子缩放，**p 值、方向、显著性完全不变** —— 与 N 不变性一致。）

校正后（`code/21_mr_corrected_N.py` → `mr_corrected_N.csv`）：

| 暴露 | 校正后 β（每 SD） | OR（每降 1 SD） | 95% CI | p |
|---|---|---|---|---|
| BMD 全身 | −0.337 | **1.401** | 1.341–1.464 | 3.7×10⁻⁵¹ |
| 股骨颈 BMD | −0.351 | **1.420** | 1.338–1.507 | 7.7×10⁻³¹ |

**vs GEFOS 1.55（1.48–1.63）→ 差异仅 8.4%，置信区间重叠。**

✅ 这同时完成两件事：① 用独立队列的发表基准**外部验证了整条流水线**；② **反证 BMD 的 N=31,873 正确**。
（OA_knee 不需校正：其 N 为 per-SNP，107,795 个唯一值，是真实 meta 分析。）
