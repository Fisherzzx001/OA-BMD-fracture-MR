## 0. 为什么 N 必须由**外部元数据**决定（不能从数据反推）

LDSC 的识别关系是：

$$E[\chi^2_j] = 1 + \frac{N h^2}{M}\,\ell_j + \frac{N a}{M}$$

回归斜率只给出乘积 **N·h²**，因此 **h² 与 N 不可同时识别**：h² ∝ 1/N。
这意味着——**改变 N 只是在同一条曲线上滑动**，拟合优度不变、截距不变。所以：

- ✅ **N 必须由来源方报告的元数据确定**（OpenGWAS/GEFOS/原文）。
- ✅ **r_g 与 MR 的方向、显著性不受 N 影响**（r_g = gencov/√(h₁h₂)，N 在分子分母中约掉；
  已实证：N 变动 6.7 倍，r_g 三位小数不变）。
- ⚠️ **只有 h² 绝对值与 liability 转换会随 N 改变** → 这正是本表要锁的。

## 4. 外部基准校验（重要，建议投稿前做）

GEFOS 2018 的 MR 给出：**股骨颈 BMD 每降低 1 SD，骨折 OR = 1.55（95% CI 1.48–1.63，P=1.5×10⁻⁶⁸）**。

本项目的 BMD→fracture：β_IVW = **−1.19 ~ −1.24**（方向：高 BMD 降低骨折，**与 GEFOS 一致** ✅）。

⚠️ 但**量级需核对单位**：
- 若 BMD 为 **SD 单位**：1 SD 升高 → OR = e⁻¹·¹⁹ ≈ 0.30（1 SD 降低 → OR ≈ 3.3），比 GEFOS 强约 2 倍；
- 若 BMD 为 **g/cm²**（股骨颈 SD≈0.13）：换算后 1 SD 降低 → OR ≈ 1.17，比 GEFOS 弱。

**行动**：确认 BMD 汇总统计的效应单位后，与 GEFOS 的 OR 1.55 对齐复核。
方向一致是核心定性结论（不受影响）；量级差异需在讨论中说明或校正。
