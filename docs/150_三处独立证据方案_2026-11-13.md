## 0. 先纠正一处自我误判（影响 M6 方案设计）

`docs/149` 把 M6 写成"knee-OA 功效不足导致 0/31"。**核验稿件正文 L49 后纠正**：膝 OA GWAS 是 **GO Consortium 2025, N≈1.21M**（不是小样本）。因此：

- 0/31 膝 OA 共定位 **不是** "因为膝 OA 样本小"——1.21M 已是超大 GWAS。
- 真正致命的矛盾是：**BMD→kneeOA 的 MR 是显著的（Table 2 OR≈1.08+），但 31 个 BMD 工具位点中 0 个与膝 OA 共享同一因果变异（PP.H4≥0.8 为 0）**。
- 这意味着：BMD→膝OA 的因果信号**并非由 BMD 的 lead SNP 在同一位点驱动**，而更可能是 (a) 水平多效 / (b) 位点内 LD 不同的独立信号 / (c) 跨多位点的聚合效应。**这恰恰支持"两个独立模块"而非"单一设定点"**。

→ M6 的正确做法不是"去找更大的膝 OA GWAS"（已经有了），而是**诚实的功效重算 + 三性状共定位 + 与显著 MR 的矛盾解释**。M2 的"单一设定点"主张，当前其实是被**稿件自己的共定位结果削弱**的，而不是被它支持。

## 2. M1 · 尺度重建（√3.543）的独立证据 —— **可行性最高，本地资产已齐**

### 2.1 要证明什么
"Qian 2025 暴露 β/SE 是按 placeholder N=400,000 尺度存入，须 ×√(400000/31873)=×3.543 还原到真 N=31,873" 是一个**尺度假设**，不是被独立验证的事实。若存入选在真 N 尺度，则 ×3.543 是 3.5× 灾难性错误；若两者都不对（比如差 ±20%），则所有 BMD→OA 估计与"与 Hartley 差 3.6–5.8×"的辩解都被污染。

### 2.2 决定性检验：同性状、跨研究的变异级 β 量级比对
**核心逻辑**：`BMD_total_N31873`（Qian）与 `BMD_total_N31986`（UKB total-body DXA）是**同一性状（全身 DXA BMD，g/cm²）、同一数量级 N（≈32k）、由两份不同研究独立测得**。对同一 SNP，两者每等位基因 β 在抽样噪声下**必须几乎相等**。
- 若 `β_Qian(raw)` ≈ `β_UKB` → Qian 已在真 N 尺度 → **×3.543 错误（过度校正）**。
- 若 `β_Qian(raw)` ≈ `3.543 × β_UKB` → **×3.543 正确**（Qian 存入选在 400k 尺度）。
- 若比值为任意其他因子 f → 量化并修正；f 即真实尺度错配因子。

### 2.3 执行步骤（复用 `code/343_scale_chain_verify.py` 框架，新增对照臂）
1. 用 TwoSampleMR `harmonise_data` 或 LDSC `--merge-alleles` **保留 MAF** 重 munge 两份 BMD（当前 munged 仅有 Z/N，需补 MAF 以反推 β；或直接从 harmonised 的 `eaf` 取 EUR 频率近似）。
2. 等位基因对齐（A1/A2 + 链方向），取重叠 SNP。
3. 逐 SNP 计算 `ratio = β_Qian(raw) / β_UKB`；报告中位数 + bootstrap 95% CI（≥1000 次）。
4. 同时验证"重标后"：`β_Qian(rescaled) / β_UKB` 应 ≈ 1（若 2.2 的 raw 比值验证 rescale 正确）。
5. **升级现有 GEFOS OR 基准**：用 `ebi-a-GCST005348`（全身 BMD N=56,284，与本研究全身 BMD 同性状）替代股骨颈 GEFOS，做 OR 级而非 log-odds 级的对照，消除"股骨颈 vs 全身"性状错配噪声。

### 2.4 预期结果与结论分支
| 结果 | 含义 | 对稿件影响 |
|---|---|---|
| raw 比值 ≈ 1（CI 含 1） | Qian 本就在真 N 尺度 | **M1 致命**：撤除 ×3.543，所有 BMD→OA 点估计需 ÷3.543，结论量级重写 |
| raw 比值 ≈ 3.543（CI 含之） | 尺度重建正确 | M1 闭环，可作"变异级独立验证"入正文 |
| raw 比值 = f（如 1.2 / 0.8） | 存在 ±20% 系统误差 | 用 f 重标，更新 GEFOS 基准与所有 BMD→OA 估计；这正是稿件目前 log-odds 比 GEFOS 低 ~20% 的解释 |

### 2.5 工作量
**低**。两份 BMD sumstats 已 munge 在盘；只需补 MAF、对齐、算比值 + 1 个 IEU 下载（`ebi-a-GCST005348`）。预计 1 个脚本（`code/351_m1_variant_level_scale_test.py`）+ 1 个 JSON。

## 3. M2 · SOS"单一设定点"内核的独立证据 —— **当前最危险，须靠结构证据救**

### 3.1 要证明什么
SOS 内核 = "同一遗传设定点驱动 BMD↑，沿同一组变异在骨折端固定相反符号、在关节端固定相同符号"。R1 双模块检验（ρ̂=−0.11，CI 含 0）只是否定"严格共线 ρ=−1"，**完全分不清设定点 vs 两个独立模块**。而稿件自己的共定位（9/31 与骨折共享、0/31 与膝 OA 共享）实际上**否定**"同一变异集同时驱动两端"。

### 3.2 检验 A（首选、用现有数据）：秩-1 遗传协方差检验
**核心逻辑**：若 SOS 成立，{10 个 BMD 位点、骨折、膝 OA} 的遗传架构由**单一潜变量**驱动 → 其遗传协方差矩阵应 **rank-1**（一个非零特征根）。若由"骨保护模块 + 关节损伤模块"两个独立轴驱动 → rank-2。
1. 从 13×13 r_g 矩阵取子矩阵 {BMD 位点们, 骨折, 膝 OA}。
2. 补算 `rg(fracture, kneeOA)`（两者均在 IEU/GEFOS/GO 可取，跑一次 cross-trait LDSC 即可）。
3. 对 3×3（或更大）遗传相关矩阵做特征分解；报告第一特征根占比 `λ1/Σλ`。
4. **判定**：λ1/Σλ ≈ 1 → 支持单一设定点；若 λ1、λ2 同量级 → 两模块，**SOS 内核被削弱**。

### 3.3 检验 B（决定性）：三性状共定位（BMD + 骨折 + 膝 OA）在 9 个骨折共享位点
1. 在稿件已确认的 9 个 BMD–骨折共定位位点（±500 kb），对**膝 OA（GO 2025, 1.21M）** 跑 `coloc.abf` 三性状扩展（或用 `moloc`/`coloc` 的 3-trait）。
2. 判读：
   - 若这 9 个位点膝 OA 也出现 **PP.H4（共享同一变异）** → 同一变异驱动三端 → **SOS 获强支持**。
   - 若膝 OA 呈 **H3（不同独立变异）或 H0** → 骨折与膝 OA 由不同变异驱动 → **两模块，SOS 内核瓦解**。
3. 这正是把 M6 的"0/31"从"功效问题"转为"结构证据"的关键一步。

### 3.4 检验 C（补充，强化叙事）：triad 位点计数
在 31 个 BMD 工具位点，统计"**BMD↑ ∧ 骨折↓ ∧ 膝OA↑**"三联符号一致的位点占比。若三联一致位点占主导 → 设定点；若 BMD–骨折与 BMD–膝OA 由不相交 SNP 集驱动 → 独立模块。

### 3.5 预期结果与结论分支
| 结果 | 含义 | 对稿件影响 |
|---|---|---|
| λ1 主导 + 9 位点三性状 PP.H4 + triad 主导 | 单一设定点成立 | M2 闭环，SOS 从"主张"升为"被结构证据支持" |
| λ2 同量级 或 9 位点膝 OA 呈 H3/H0 | 两独立模块 | **M2 致命**：SOS 内核须降级为"相关但不因果同源"，结论框架重写 |
| 混合 | 部分支持 | 如实陈述"存在共享设定点成分，但非全貌" |

### 3.6 工作量
**中**。检验 A 只需补一次 LDSC + 特征分解（1 脚本）；检验 B 需 3-trait coloc 包（R `coloc`/`moloc` 或 Python `coloc`）；检验 C 在现有 harmonised 上计数。预计 `code/352_m2_kernel_evidence.py`（A+C）+ R 桥接脚本（B）。

## 4. M6 · 共定位"端点特异性"的独立证据 —— **必须诚实重算功效，而非找更大样本**

### 4.1 要证明/澄清什么
稿件当前表述"9/31 vs 0/31 由共定位功效驱动，非已确立的端点特异性"。但膝 OA 已是 1.21M，**不能再用"样本小"搪塞**。正确做法是：要么证明 0/31 在现有数据下**统计上可预期**（则不具信息量），要么承认 0/31 与"显著 BMD→膝OA MR"的矛盾**揭示水平多效/独立模块**。

### 4.2 检验 A：逐位点共定位功效模拟（Wallace 2014 框架）
1. 对 31 个位点，用观测 MAF、膝 OA N=1.21M、观测每位点 BMD→膝OA 效应，模拟"共享因果变异为真"时 PP.H4 的分布（参考 `pmc.ncbi.nlm.nih.gov/articles/PMC7192519` 的先验/功效方法）。
2. 判读：若 31 个位点期望 PP.H4 中位数本就 <0.8 → 0/31 是**功效不足、无信息量**（支持稿件"非端点特异性"表述）；若多位点期望 PP.H4>0.8 却观测为 0 → **真缺失**，支持独立模块。

### 4.3 检验 B：与显著 MR 的矛盾解释（核心）
- 用 conditional / fine-mapping（COJO 或 `coloc` 的 masking）在每位点检查：BMD 的 lead SNP 是否就是膝 OA 的因果 SNP。
- 若 BMD lead SNP 与膝 OA 因果 SNP **LD 不同**（不同索引 SNP）→ 解释"MR 显著但共定位 0/31"= 水平多效或跨位点聚合，**不支持单一设定点**，与 M2 联动。

### 4.4 检验 C：EUR-only 膝 OA 复跑（已部分在 S33）
稿件 S33 已用 EUR-only 膝 OA 做方向复制（保 5/5 r_g 正）。在此之上跑 EUR-only 膝 OA 的共定位，排除多祖先 LD 结构对 PP.H4 的稀释。若 EUR-only 下仍 0/31 → 进一步坐实"非功效、是结构"。

### 4.5 预期结果与结论分支
| 结果 | 含义 | 对稿件影响 |
|---|---|---|
| 功效模拟：期望 PP.H4 本就低 | 0/31 无信息量 | 保留"非端点特异性"表述，但须**改写 L13 措辞**（去掉"需 5×10⁷ 人"这种误导性论据，改为逐位点功效曲线） |
| 期望 PP.H4 高却观测 0 | 真缺失 + 与 MR 矛盾 | **M6 升级为 M2 的佐证**：两独立模块；SOS 内核须降级 |
| EUR-only 仍 0/31 | 非多祖先 LD 稀释 | 排除一项混淆，保留结构解释 |

### 4.6 工作量
**中低**。检验 A 是纯模拟（Python/R，输入为已观测 MAF/N/效应）；检验 B 用现有 harmonised + GO2025；检验 C 复用 S33 管线。预计 `code/353_m6_coloc_power.py`。

## 9. M1 独立 BMD 验证：本次环境实测结论与可复现交付（2026-11-13）

**用户指令**：用独立 BMD GWAS（IEU ieu-a-980/982、ebi-a-GCST005348）跑 `code/351 --independent`，补上 M1 的"独立 BMD GWAS 验证"缺口。

**实测环境网络事实（逐一验证，非推测）**：
1. **IEU OpenGWAS v2 需 JWT**：`POST api.opengwas.io/api/associations` 返回 `401`，明确"自 2024-05 起大部分请求须带 JWT"；`gwas.mrcieu.ac.uk/api/...` 已 301 重定向到 `opengwas.io` SPA；`api.opengwas.io/api/download/ieu-a-980` 等下载端点均 404。无浏览器 OAuth 无法取得 token → IEU 路径在本环境堵死。
2. **EBI FTP 被限流/封锁**：GCST005348 harmonised（468 MB）的早期并行下载被代理不规则截断（0.5MB 块完整、1MB 仅回 624KB、2MB 回 0、高位偏移 400KB 也仅回 136/320KB）；后期全新 256KB 分块直接返回 0 字节（30s 超时）→ EBI FTP 现已不可达。
3. **EBI REST v2 剥离查询参数**：`/associations?variantId=rs12568930`、`?studyAccession=GCST005348` 等均被代理吞掉参数，返回默认全库 1.2M 关联（无法按 SNP/研究过滤）→ 无法按 31 个 SNP 远程提取。
4. **GitHub raw 被封**：`raw.githubusercontent.com` 返回 HTTP 000。
5. **可达但无用**：`opengwas.io`（需 JWT）、`ebi.ac.uk` REST 根（参数被剥）。

**结论**：本环境此刻**无法拉取任何独立 BMD GWAS 原始数据**，M1 变异级独立验证的"数据获取"环节被环境代理阻断。代码与方法学已全部就绪，仅缺外部文件。

**已交付的 turnkey 方案（在开放网络处一键可跑）**：
- `code/351b_independent_scale_test.py`：按 (CHR,BP) 位置匹配 GEFOS total-body BMD（GCST005348，与暴露同性状）到 31 个 MR 工具，等位基因对齐后算 `median(β_GEFOS/β_exposure)`，判定 ×3.5426 是否过膨胀（≈1→错；≈3.5426→对）。已加 `variant_id`(chr:pos) 兜底。
