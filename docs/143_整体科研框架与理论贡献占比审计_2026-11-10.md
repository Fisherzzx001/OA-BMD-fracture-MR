## 0. 一句话结论

**框架已具备顶刊级完整度且四门禁全绿；方法学/理论贡献的"篇幅占比"在 OAC 原创论文范畴内合理，但存在一处结构性不对称——方法学是"数据衍生且已验证"，SOS 理论是"数据衍生但机制证据仍偏器官级、部分属事后框架"。**
因此真正需要加强的**不是把理论写得更长，而是把 SOS 的证据密度从"器官级 r_g + 端点分裂共定位"下沉到"细胞/组织级机制"**。本轮爬取的三个发现恰好提供了几乎零成本的下沉路径（见 §5）。三个未闭合检验（F2 体积臂/F5 髋骨赘/F10 跨祖先）在 2026 年最新公开数据下依然不可执行，诚实披露策略不变。

### 1.2 逻辑自洽性与被追问点

- **强**：§3→§4 叙事与 Table 2/3 数值逐句咬合；"高 I² 是 BMD 工具集属性而非 OA 特异失败"用正控同质性（78–83%）反证，成立。P6 从"量级断言"恢复为"方向断言"（F1 髋估计 z=0.94）的降级—升级处理是教科书级诚实。

## 3. 方法学 vs 理论贡献占比：是否合理？

### 3.1 量化画像

| 维度 | 方法学 | 理论（SOS） |
|---|---|---|
| 正文篇幅（估算） | Methods+Results ≈ 75% | Discussion 的 SOS/P-F 段 ≈ 25% |
| 证据来源 | **数据衍生且已验证**（自研 LDSC、MR、MRlap、复现 GEFOS/文献） | **数据衍生 + 已发表生物学推断**（骨-软骨单元、RSPO3-NFATC1、骨赘三联） |
| 可证伪性 | 内建（正控、敏感性、功效边界） | 内建（P1–P6 预测 + F1–F10 证伪，预注册） |
| 直接证据密度 | 高（逐表可复现） | **中偏低**（机制主体为端点分裂共定位 + 器官级 r_g；细胞/组织级为间接/脚注） |

### 3.2 判断

**占比数字本身合理，甚至优于同类 MR 论文**——多数 BMD–OA MR 只有"关联+MR+敏感性"，本文额外提供了统一理论、6 预测、10 证伪检验和预注册，理论陈述强度超出领域平均。**但结构性不对称真实存在**：读者/审稿人看到的是"极其扎实的方法学 + 一个讲得通但证据偏间接的理论"。

三个具体表现：
1. **SOS 的判别式内核锐利，但机制锚点放在脚注**：ref [47]（RSPO3–NFATC1 单细胞证据）目前只在 S30 note vi 作"reverse inference"，而非 §4 的正面支柱 → 把最强的现成机制证据放低了。
2. **P3「0/31 共定位」是理论Predict，但方法单一**：coloc.abf 假设单位点单因果；2025–2026 标准已转向 coloc-SuSiE（多信号位点）。换方法的稳健性检验能显著提升这条预测的判别力。
3. **"事后理论"风险**：P1–P6 是"derived predictions"（数据衍生）、F1–F10 才是 pre-registered。OSF 独立预注册（10.17605/OSF.IO/CSMP7）已声明这一点，是防御 HARKing 质疑的关键资产——但需要在 cover letter/rebuttal 中**主动、明确**地把这条叙事讲出来，而不是等审稿人问。

**结论**：不建议"增加理论篇幅"（正文已 3982/4000 零余量，且缺口不在字数）；建议"提升理论的证据密度"——把已有/易得的细胞级证据顶到前台（§5）。
