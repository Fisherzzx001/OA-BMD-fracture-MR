## 2. 本次新发现的问题（前次审计遗漏）

### 🔴 A. MEDIUM — §3.7 效应量重建叙事方向写反了
- **位置**：`docs/08` 第 126 行。
- **问题**：原文写 *"β_reconstructed = β_SD·√(N_true/N_used)，every BMD effect was **underestimated** by √(31,873/400,000) = 0.282 (i.e. 3.54-fold)"*，但**实际应用的修正是除以 3.54**（校正后 β 更小），说明被 munged 的 β 是**被放大了 3.54×**，而非"低估"。
  - 逻辑核验：若 munged β  underestimated（太小），则正向 MR（BMD 为暴露）β 也偏小，修正应 **×3.54**；但数据明确显示校正 = **÷3.54**（校正后更小）。故原文"underestimated"与所施加的修正**方向相反**。
  - 此外，"N=400,000" 占位符在 `SE=1/√(N·2pq)` 公式下只能产生 ×0.282 的**缩小**，数学上无法产生文中所述 3.54× 的**放大**——叙事的机理数值与修正方向不自洽。
- **影响**：数值正确（GEFOS 已外部验证），但方法学审稿人会发现"低估"措辞与 ÷3.54 修正矛盾，可能质疑方法严谨性。
- **修复建议**：改为 *"munged BMD 效应量被整体放大 3.54×：β_munged = β_SD·√(N_used/N_true) = β_SD×3.5426（即 N_used/N_true≈12.55，√≈3.54）；SE 与 β 同标度缩放，故 z/p/方向不变，仅 IVW 绝对值需在 BMD 为暴露时 ÷3.54、为结局时 ×3.54（见 §3.6）"*。

### 🟠 B. MEDIUM — femoral-neck OR：正文 1.44 与 Table 3（严格 clump）1.42 不一致
- **位置**：§3.3 第 90 行（"OR = 1.44, 95% CI 1.36–1.53"）；§3.7 第 128 行（"OR = 1.44 (…) for femoral-neck BMD"）。
- **问题**：独立重算严格 clump（Table 3）femoral-neck→fracture = β −0.3507 → **OR = 1.420 (1.338–1.507)**；而正文报告的 1.44 是 **1-Mb clump**（β −0.3654 → OR 1.441）的值。两者差 1-Mb vs 严格两种 clump 基准，但稿件未统一主分析。
  - 连锁后果：§3.7 称差距"8–10%"，该说法**仅对严格值 1.42（8.4%）成立**；若按正文 1.44 算，差距仅 7.0%，与"8–10%"矛盾。
- **修复建议**：将 femoral-neck 头条 OR 改为 **1.42 (1.34–1.51)** 以与 Table 3（严格，主分析）一致；把 1.44 明确标注为 1-Mb 敏感性（正文括号"strict-clumped sensitivity: 1.40 and 1.42"中 1.42 已正确，只需改头条）。
